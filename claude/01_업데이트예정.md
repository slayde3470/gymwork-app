## A. 하기로 확정한 것 (아직 안 만듦)

- **㉔ 잠금 화면 [세트 완료] · [휴식 끝] 단추 — 안드로이드 16 '라이브 업데이트' 때 넣는다** (10-15 홍겸 님: "라이브업데이트때 기능을 넣자. 지금은 기능 다 어플에서 빼"). **지금 앱에는 없다** (v 10-15 에 전부 뺌 — 예전 설치가 남긴 알림 · 채널은 첫 실행 때 한 번 치움).
  - 하려던 것: 폰이 잠겨 있어도 운동 중 알림에서 ✓ 로 세트를 체크하고, 휴식 끝 단추로 쉬는 시간을 건너뛴다.
  - **해 본 것** (폰: 삼성, 이어폰 연결 상태)
    - 보통 알림(중요도 낮음 → 기본): 코드로는 올라갔다고 나오는데 **잠금 화면 · 알림판에 한 번도 안 떴다.** 원인은 못 찾음
    - 미디어 알림(MediaStyle + MediaSession, 단추 2개): **잠금 화면 미디어 칸에 떴고 ✓ 단추는 폰에서 실제로 세트를 체크했다.** 골랐던 아이콘: 세트 완료 = 동그라미 안 체크(#9) · 휴식 끝 = 시계에 사선(#2). 누르면 짧은 진동. 앨범 그림 = 앱 아이콘(♪ 없앰)
    - 막힌 것: 이어폰이 연결되어 있으면 **삼성이 미디어 칸에 자기 버즈 버튼 · 출력 기기 칩을 붙인다** — 앱이 숨길 수 없다 (조사: 공식 방법 없음). 원격 재생(`setPlaybackToRemote`)으로 피하는 길은 **볼륨 키를 가로채서 권하지 않음.** 이어폰 미디어 버튼이 이 세션으로 가는 부작용도 있다
  - **라이브 업데이트로 가는 길** (조사 결과 · **확인 안 된 것은 추측**): 일반 진행 알림 + 단추(Action) 에 `setRequestPromotedOngoing(true)` · 권한 `POST_PROMOTED_NOTIFICATIONS` (안드로이드 16 · API 36.1). 제약: 커스텀 뷰 · 색 입히기 불가. 삼성 One UI 는 잠금 화면 알림을 **기본 '아이콘만'** 으로 보여 준다 → 사용자가 설정 > 알림 > 잠금 화면 알림을 '카드'로 바꿔야 할 수 있음. Now Bar 는 삼성이 허용한 앱만 뜨는 듯(One UI 8.5 이상에서 비공식 extra `android.ongoingActivityNoti.automation` 이야기가 있음 — **추측**). 이 폰이 안드로이드 16 인지 · 위 알림이 실제로 잠금 화면에 뜨는지는 **만들어 봐야 안다**
  - 앱에 남은 것: 동그라미 꾹 누름 배너(`밖알림`) · 휴식 끝 알람(**진동만, 소리 없음**)

## C. 써 보면서 정할 것

- **⑥ 매 종목 '루틴 향상도'를 보여줄 필요가 있나** (09-20 "써보며 체크") — 지금 운동 화면 위쪽은 `루틴 달성도` · `이 운동 달성도` 둘. 종목 단위 변화는 위 세 칸의 이전/최고가 대신한다. 세 칸으로 충분한지 몇 번 써보고 결정
- **⑦ 세트 번호 옆 `▾` 의 원래 뜻 모름** — 지금은 오른쪽 `⌄` 와 같이 설정 칸을 연다(지어내지 않음). 세트 종류(워밍업 · 드롭세트)를 고르는 것이었다면 그와 맞춰야 한다. 세트 종류 칸은 v0.9.0 에 생겼으나(0 본운동 · 1 워밍업 · 2 측정) **운동 중 화면의 워밍업·측정 줄은 아직 없다**
- **⑧ `← 이전` → `≡ 운동 목록`** (09-21 해결) — 오늘 루틴 전체 목록에서 아무 종목으로 건너뜀. 남은 것: 한 세트 되돌리기 버튼이 따로 필요한지 써보고(체크를 다시 눌러 푸는 길은 있다)
- **⑪ 성장율 왜곡 방지** (09-21: "사용하면서 감을 잡아야 할 것 같아") — 지금 **① 같은 세트 수까지 잘라 견주기**로 돈다. 다시 볼 때: 세트를 줄인 날 과거도 같이 잘려 실제보다 좋아 보이지 않는가 · 늘린 날 억울하지 않은가 · 종목을 더한 날 루틴 선이 튀지 않는가. 대안: ② 세트당 평균 볼륨 · ③ 그 날 가장 좋은 세트 하나(1RM) · ④ 구성이 바뀐 날은 점선 · ⑤ 원래 있던 종목만. 여러 개를 설정에서 고르게 해도 됨. `대비()` 한 함수만 손보면 된다
- **⑮ 캘린더 `휴식` 버튼이 직관적인가** — 선택지마다 앞으로 사흘을 미리 보여 준다(`오늘 쉼 · 내일 가슴날 …`). 써보고 헷갈리면 말을 바꾸거나 선택지를 줄인다
- **⑯ 피로 누적 기준 — 데이터로 다시 세우기** (09-22 홍겸 님: 이전 최대 볼륨을 '일시적'으로 쓰고 쓰면서 데이터를 보고 정하자) — 지금: 단계 = min(20, 20 × 오늘 유효 볼륨 ÷ 그 근육의 이전 최대 유효 볼륨), 유효 볼륨 = 무게×횟수×역할 비중(주동 1 · 보조 0.5 · 협응 0.25), 기록이 없으면 오늘 계획이 기준 (`07_근육지도규칙.md`). 볼 것: 한 번 크게 넘긴 뒤 평소가 계속 옅게 보이지 않나 · 처음 하는 근육이 가볍게 해도 20단계로 빨개지지 않나 · 0.5/0.25 비중 · 휴식 시간이 단계에 비례하는 것. 후보: ② 최근 4주 평균×1.3 · ③ 최근 N회 중 최대 · ④ RPE/근육통 입력 보정. 근육별 하루 유효 볼륨을 모두 저장하므로 기준을 바꿔도 다시 계산된다
