# 홍겸 님 작업 방식 · 앱 방향

> 클로드코드에서 일할 때의 '기억'. 새로 알게 된 작업 방식은 여기에 더한다.
> 저장소가 공개라 개인 신체 · 운동 기록은 넣지 않는다. (2026-10-25 claude.ai 기억에서 옮겨 시작)

## 답하는 법
- 보고 · 요약 · 답변은 **한국어**로 (영어는 못 알아듣는다 · 09-21)
- APK 를 보고할 때 **눌러서 바로 받는 링크**를 같이 준다 (09-21 · 10-14)
- 간단한 수정에 10~20분 · 많은 토큰을 쓰면 안 된다 (10-03)
- 여러 일을 동시에 하고, 쓸데없이 기다리지 않는다 (10-09)

## 일하는 법
- 홍겸 님이 **답하지 않은 것 · 제안하지 않은 것 · 확인하지 않은 것**은 임의로 하지 말고 먼저 묻는다 (09-20 "꼭 기억해")
- 요구를 **한꺼번에 여러 개** 넘기면 중간에 "계속할까요?" 묻지 말고 끝까지 한다 (09-21)
- 요구한 항목을 **혼자 판단해 빼거나 안 하면 안 된다** (10-08)
- 알고리즘(계산 규칙)은 임의로 해석하지 말고 **최대한 많이 물어보며** 만든다 (10-03)
- 한 번 말한 요구가 잘 안 됐는데 다시 몇 차례 말하지 않으면 그 요구는 붙들지 않는다 (09-24)
- 작은 수정은 도우미 없이 바로 고치고 바뀐 곳만 확인 · 문서 정리는 "정리해" 할 때 한 번에 (그 전엔 `문서/작업일지.md` 한 줄씩) · 표시 한 묶음마다 새 세션 (10-03)
- 합의 내용은 **확정됐을 때 한 번만** 문서에 쓴다 · 근거 조사와 시안은 종목마다 새로 (09-28)
- 나중에 넣기로 한 기능은 `claude/01_업데이트예정.md` 에 (09-20)
- "새 세션에 알려줄 내용 정리해줘" → 실제로 확인된 작업 통로(도구 · 되는 길 · 안 되는 길 · 대체 길)를 구체적으로 (09-21)

## 화면 · 설계 원칙
- UI 는 앱보다 **아티팩트(시안)로 먼저** · 요구보다 크게 바꾸지 않는다 (09-24)
- **① 스크롤 없이 ② 한 화면 안에서 ③ 손이 덜 왔다 갔다** (09-24)
- 숫자 · 규칙표 · 색 · 문구는 **한곳에 모아** 쉽게 고치게 (09-27)
- 새 기능 · UI 를 고치거나 더하거나 지울 때 **`claude/11_UI지침.md` 먼저** · 없는 값은 지침부터 고친다 (10-02)
- **"beta 표시"** = 그 단추 · 기능 오른쪽 위에 빨간 박스 · 흰 글씨 `beta` → "홍겸 님이 나중에 결정" (09-29)
- 사용자가 단추를 누를 일을 최대한 줄인다 — 앱이 주는 종목은 기본 세팅을 미리 다 해 두고, 조절은 커스텀 종목에서만 (10-12)

## 앱 방향
- 홍겸 님 폰: **갤럭시 S26 울트라**
- 본인부터 쓰고 주변에 권유 → 괜찮으면 출시. 처음부터 출시를 대비해 설계 · 업데이트 때 기록이 이어지는 것이 중요
- 나중에 유료 플랜 계획 (10-03). 보상으로 공유를 유도하기보다 결과 화면을 공유하고 싶게
- 앞으로 다른 앱도 만들 계획 — 기본 동작방식(`문서/동작방식.md`)을 복사해 쓰려 한다
- 근육지도: 제미나이 · GPT 로 사실적인 회색 밑그림 → 색칠 지도는 Claude. 원색 대신 고급스러운 색 · 그라데이션, 볼륨 있는 체형 (10-09)
- 토큰이 빨리 떨어져 작업이 끊기는 것을 가장 불편해한다
