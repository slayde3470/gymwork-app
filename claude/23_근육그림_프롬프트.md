# 23 근육 그림 프롬프트 (제미나이 · GPT 용) — 10-09 시작 · 홍겸 님과 다듬는 중

**언제 읽나** — 앱 근육 그림(회색 밑그림)을 새로 받거나 다시 받을 때만. 규칙은 `07_근육지도규칙.md` 9절(그림 8가지 · 2장 규칙).
**방식** — 이미지 모델은 **회색 밑그림만** 만든다. 색칠 지도(근육 이름표)는 Claude 가 밑그림을 따라 그린다(10-09 홍겸 님). 화면에 보이는 색 · 그라데이션은 앱 색표가 정한다.

## 쓰는 법
1. 대화마다 **그림 1장.** [A 스타일 고정] + [B 체형] + [C 이번 그림] 을 그대로 붙인다. A 는 절대 고치지 않고 통째로 쓴다(매번 같아야 조명 · 질감이 같다).
2. **스타일 기준 그림**을 함께 첨부한다 — 지금은 `전신 앞`(10-09 받은 것). 여자판도 같은 기준 그림을 첨부(조명 · 재질 · 구도를 맞추려고 — 체형은 B 를 따른다).
3. 여러 칸 모음 그림은 첨부하지 않는다(따라서 여러 명을 그린다).

## A. 스타일 고정 (남녀 공통 · 바꾸지 않는다)
```
[A. 스타일 고정 — 아래 값을 정확히 지켜. 첨부한 기준 그림과 조명 · 재질 · 구도가 똑같아야 한다]
- 그림 1장에 사람 1명, 한 방향만. 캐릭터 시트 · 턴어라운드 · 여러 각도 모음 금지.
- 재질: 무광 회색 클레이 조각(ZBrush 기본 회색 MatCap 느낌). 바탕색 하나 #C9CDCA. 반사광 · 광택 0%. 피부결 · 모공 · 털 · 붓자국 · 긁힌 자국 · 노이즈 0%.
- 근육 표현: 근육 덩어리 사이 경계 홈만 — 모든 부위에서 같은 깊이(얕고 부드럽게, 폭 2~3픽셀 그림자). 근섬유 결 줄무늬 0%, 힘줄 · 핏줄 0%. 몸 전체가 같은 매끈함.
- 조명(스튜디오 3점, 고정): 주광 = 왼쪽 위 45°에서 100% · 보조광 = 오른쪽 앞 30°에서 40% · 윤곽광 = 뒤 위에서 20%. 그림자는 부드럽게. 가장 어두운 그림자도 #70746F 보다 어둡지 않게. 가장 밝은 곳도 #E6E9E7 보다 밝지 않게.
- 카메라: 원근 왜곡 없는 정사영에 가깝게(망원 85mm 이상), 높이 = 배꼽 높이, 수평.
- 배경: 순백 #FFFFFF 한 가지. 바닥 · 바닥 그림자 · 반사 · 글자 · 테두리 · 워터마크 없음.
- 머리: 이목구비 없는 매끈한 달걀형 마네킹 머리(귀 윤곽만). 머리카락 없음.
- 사타구니 · 가슴: 매장 마네킹처럼 매끈하게 막힌 면. 성기 · 성기 윤곽 · 불룩함 · 주름 없음. 젖꼭지 · 배꼽 없음.
```

## B-남. 체형 (남자)
```
[B. 체형 — 남자] 파워빌더 체형(thick powerbuilder, bulky offseason). 체지방 15~18% — 근육 위에 살이 얇게 덮여 표면이 둥글다.
- 비율: 8등신 아님 · 7등신. 어깨 너비 = 키의 30%, 허리 너비 = 어깨의 72%, 골반 너비 = 어깨의 68%.
- 가슴: 꽉 차고 둥글게 앞으로 튀어나옴, 아래쪽 둥근 선반 그림자.
- 엉덩이: 크고 둥글고 위로 솟음, 옆에서 뒤로 확실히 튀어나옴(살짝 과장).
- 허벅지 · 종아리 굵고 둥글게. 허리 · 몸통 두껍게.
- 하지 말 것: 마른 몸 · 줄무늬 데피니션 · 핏줄 · 각진 근육 · 가는 허리 · 납작한 가슴/엉덩이.
```

## B-여. 체형 (여자)
```
[B. 체형 — 여자] 탄탄한 근육형 여성(athletic, strong, curvy). 체지방 20~24% — 근육 위에 살이 덮여 매끈하고 둥글다.
- 비율: 7.5등신. 어깨 너비 = 키의 25%, 허리 너비 = 어깨의 70%, 골반 너비 = 어깨의 95%.
- 가슴: 마네킹처럼 매끈한 가슴 볼륨(젖꼭지 없음), 그 위 · 옆으로 대흉근과 어깨 앞이 이어지는 선이 보이게.
- 엉덩이: 크고 둥글고 위로 솟음(살짝 과장). 허벅지 · 종아리 탄탄하고 둥글게. 어깨 · 팔은 근육이 보이게 둥글게.
- 하지 말 것: 마른 몸 · 줄무늬 데피니션 · 핏줄 · 남자 같은 각진 몸통 · 납작한 엉덩이.
```
