## 2. 루틴 · 숫자 입력
- 숫자 칸을 누르면 **자판과 휠이 같이** 뜬다. 휠을 만지면 자판이 내려간다. **휠은 돌려도 값이 안 바뀐다** — 가운데 숫자를 **눌러야** 들어간다(가운데 칸에 '누르면 선택' 테두리)
- ~~빈 곳을 누르면 취소~~ → 09-24 에 **취소 개념을 없앴다** (10 D4-2)
- 휴식 `분 : 초` — 초 칸에 치기 시작하면 분 칸을 비운다(60 을 치는 동안 `1:60` 이 안 보이고 `= 1:00` 으로 미리 보임). 자판 완료 = 엔터
- 종목 추가는 카드 맨 아래 검색칸 하나(누르면 자판 위로 올라옴). 루틴 이름이 두 번 나오던 것 정리
- **이름으로 부위 · 장비 자동 추천**: 이름에 `벤치` → 가슴, `컬` → 팔 … / 이름에 장비가 없으면 후보 칩(`벤치` → 바벨 · 머신 · 스미스). 규칙표는 시안 코드의 `부위규칙` · `장비후보` (앱은 `부위·장비 짐작`, v0.5.0)

## 3. 운동 중
- **시작 안 한 종목은 접는다**(홍겸 님 원래 규칙), 지금 종목만 펼침. 슈퍼세트 상자도 누르면 부드럽게 펼침/접힘
- 휴식 칸 색 초록 → 절반 이하 파랑 → 5초 이하 빨강 굵게 (시안) → ⚠ 앱은 **중심색이 꽉 찬 채 줄어든다**(10 D5-11)
- **위쪽 그림 칸(배너)** — 보기 넷 중 설정에서 고른다:

| 보기 | 칸 | 오른쪽 접힌 더미 |
|---|---|---|
| 근육 2장 | [루틴 전체 근육, 지금 부위 확대] | 없음 |
| 근육 + 사진 | [전신 ↔ 확대가 세트마다 번갈아, 사진 1장] | 사진 9장 |
| 사진 1장 | [사진] | 9장 |
| 사진 2장 | [사진, 사진] 폭 절반씩 | 8장 |

  세트가 끝날 때마다 사진이 **무작위로** 바뀐다(나가는 칸은 오른쪽 끝으로 얇게 접혀 들어가고 새 칸은 더미에서 펼쳐져 나옴). 휴식 동안 칸이 커진다(시안 180). 사진만 보는 중에도 **부위가 바뀐 첫 세트에는 새 부위 확대가 한 번** 나온다(*제 제안*). 근육 1번 칸 = 루틴 전체(끝낸 부위가 빨갛게 쌓임), 2번 칸 = 지금 부위(세트마다 차오름). ✕ 로 배너를 감춘다
  ⚠ 시안의 근육 그림은 **react-body-highlighter (MIT, © 2020 GV79)** 좌표를 옮긴 것 — 앱에서는 우리 그림(07)으로 바꿨는지 ⚠ 확인 못 함. 그대로 쓰면 MIT 저작권 표시를 넣는다
  ✦ v0.13.0: 5가지 모드(근육 2장 / 근육 + 사진 / 사진 1장 / 사진 2장 / 숨김), 쉬는 동안 높이 124 → 168, ✕ 숨김은 루틴 id 로 기억
