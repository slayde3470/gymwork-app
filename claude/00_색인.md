# 문서 색인 — 이 일에는 이 문서만 읽는다

## ⚠ 0. 먼저 — 이 일에 문서가 필요한가 (2026-10-02 홍겸 님)

**대화를 시작한다고 무조건 문서를 읽지 않는다.** 시킨 일이 무엇인지 먼저 가린다.
문서는 **앱의 기존 결정과 이어 붙여야 할 때만** 연다.

| 시킨 일 | 읽을 것 |
|---|---|
| **새 정보 가져오기** — 근거 조사 · 웹 검색 · "이거 맞아?" · 자료 찾기 | **아무것도 안 읽는다.** `research` 에이전트에 넘긴다 |
| **그냥 질문 · 설명** — "커밋이 뭐야" · "이거 왜 이래" | **안 읽는다.** 바로 답한다 |
| **지금 어디까지 했지?** | `00_작업현황.md` 0 · 1 · 2절 |
| **앱 코드 고치기 · 기능 만들기** | 아래 1절 표에서 **한두 개만** + `09_대기메모.md` |
| **시안을 앱으로 옮기기** (2026-10-05) | 저장소 `문서/앱옮기기_계획.md` → `문서/앱옮기기_목록.md` + 시안의 해당 함수. `claude/` 문서는 목록이 가리키는 것만 |
| **문서 정리 · 결정 기록** | 아래 1절 → `09_대기메모.md` → `00_작업현황.md` 0 · 1 · 2절 |
| 무엇을 할지 아직 모를 때 | 이 색인 하나만 |

**조사한 것을 앱이나 문서에 넣기로 정해진 뒤에**, 그때 비로소 관련 문서를 열어 기존 값과 견준다.
홍겸 님이 "이거랑 저거를 엮어서 봐 줘" 라고 할 때도 그때 연다. **미리 열어 두지 않는다.**

**보관 문서는 저장소 `문서/보관/` 에 있다** (2026-10-02 · 10-26 내림).
