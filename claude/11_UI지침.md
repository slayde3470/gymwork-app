# 11. UI 지침 — **UI 를 고칠 때만 읽는다**

> 이 문서는 **색 · 글자 · 치수 · 부품 · 동작**의 규칙이다.
> 화면을 하나라도 고치기 전에 이 문서를 읽고, 고친 뒤 이 문서로 되짚는다.
> 기능·플랜 계산만 고치는 대화에서는 **읽지 않는다.**
>
> 규칙마다 번호(`U2-3`)가 있다. 고칠 때는 그 번호만 고치고, 다른 데서는 번호로 가리킨다.
> 실제 값은 전부 `app/src/main/java/com/slayde/hasenheide/ui/theme/Theme.kt` 한 곳에 있다.
> 지금 상태를 번호로 늘어놓은 표: **아티팩트 `claude.ai/artifact/CtMZAZYkZMCJ3CjNcDmLoR`**

## 0. 세 가지 뜻 — 모든 규칙이 여기서 나온다

| 번호 | 뜻 | 무슨 말인가 | 어겼을 때 어떻게 보이나 |
|---|---|---|---|
| **U0-1 직관성** | 보면 안다 | 글을 읽지 않아도 뭘 누르는 것인지, 지금 어디인지 안다. 색과 모양이 **뜻**을 나른다 | 눌러 봐야 아는 단추 · 꺼진 건지 켜진 건지 모를 칩 |
| **U0-2 통일성** | 같은 일은 같은 모양 | 같은 구실을 하는 것은 화면이 달라도 똑같이 생겼다. 부품이 하나다 | 칩이 네 종류 · 섹션 제목이 두 모양 |
| **U0-3 일관성** | 값이 흩어지지 않는다 | 같은 뜻의 치수·색은 언제나 같은 숫자다. 이름으로 쓰고, 한곳에서 고친다 | 좌우 여백이 탭마다 다름 · 비슷한 글자가 11/12/13sp |

**셋이 부딪히면 직관성이 이긴다.** 통일하려다 뜻이 흐려지면 통일하지 않는다.
(예: 지우기 버튼만 빨간 글자인 것은 통일성을 깨지만 직관성이 더 크다 — 그대로 둔다)

## U1. 색

| 번호 | 규칙 |
|---|---|
| **U1-1** | 색은 `Theme.kt` 의 **색표 18개 이름만** 쓴다. 화면 코드에 `Color(0x…)` · `Color.White` · `Color.Black` 을 쓰지 않는다. **예외 둘**: `Color.Transparent`(= 색 없음), 그리기 마스크(`BlendMode` 용) |
| **U1-2** | **중심색 위의 글자는 반드시 `강조글`.** 흰색을 직접 쓰지 않는다 — 어두운 화면에서 중심색이 밝은 파랑으로 뒤집히기 때문이다 |
| **U1-3** | `.copy(alpha = …)` 로 색을 깎지 않는다. 옅은 색이 필요하면 **색표에 이름을 하나 더 만든다**. (지금 0.12 · 0.16 · 0.35 · 0.45 · 0.5 · 0.82 가 흩어져 있다) |
| **U1-4** | **뜻이 색을 정한다.** 할 수 있는 것·고른 것 = `강조` / 지우기·위험·경고 = `나쁨` / 달성 = `좋음` / 향상 오름 = `오름` / 내림 = `내림`. 보기 좋다고 바꾸지 않는다 |
| **U1-5** | 층은 셋뿐이다: `바탕` → `면` → `면2`. 네 번째 층을 만들지 않는다 |
| **U1-6** | 테두리 색은 둘뿐이다: 큰 상자 = `강조`, 안쪽 상자 = `속선` |
| **U1-7** | 값이 같은 다른 이름(`휴식`=`강조`, `내림`=`강조`, `휴식옅음`=`강조옅음`)은 **뜻이 달라 그대로 둔다.** 다만 그 둘을 **나란히 놓아 구별시키는 화면은 만들지 않는다** — 눈으로는 같은 색이다 |
| **U1-8** | ~~이야기 연결어는 색이 다르다~~ **⚠ 10-02 철회 대기** — 연결어를 1번씩만 쓰기로 해서(12-5 S1 · S2 철회) 칠할 곳 · 누를 곳이 없다. 행을 지울지 홍겸 님 확인 전. — 플레이버 안에서 되풀이되는 고유명사(`12-5_업적칭호.md` S1 · S2). 누르면 같은 이름이 나온 업적 목록이 뜬다. 색표에 **`이야기`** 라는 이름을 새로 만든다. ⚠ **색 값 미정** — 기존 18개 중 어느 것도 이 뜻이 아니다 (`09_대기메모.md` 물을 것). 플레이버는 `옅음` 기울임이므로, 연결어는 **그보다 또렷해야** 눌러 보고 싶어진다 |

## U2. 글자

| 번호 | 규칙 |
|---|---|
| **U2-1** | 크기는 **여섯 단계뿐**: `11 · 13 · 15 · 18 · 22 · 28`. 그 사이 값을 쓰지 않는다 (8 · 9 · 10 · 10.5 · 12 · 14 · 17 전부 금지) |
| **U2-2** | 크기는 숫자가 아니라 **이름**으로 쓴다 — `크기.본문`, `크기.작게` |
| **U2-3** | **자간은 글꼴이 정한다.** 보통 −0.01em · 제목 −0.02em · 이름표 +0.04em. 화면에서 자간을 직접 주지 않는다. 예외: `맞춤글` 이 한 줄에 맞추려고 좁힐 때 |
| **U2-4** | **줄 간격도 글꼴이 정한다** (보통 글자 × 1.4, 제목 × 1.25). `lineHeight` 를 직접 주지 않는다 |
| **U2-5** | 굵기는 셋뿐: `Normal`(설명) · `Medium`(목록 이름) · `Bold`(값 · 제목 · 버튼 · 이름표) |
| **U2-6** | **뜻이 크기를 정한다.** 11 = 설명·단위·작은 표시 / 13 = 보조 글·칩·버튼 / 15 = 본문·목록 이름·입력 / 18 = 카드·시트 제목·큰 값 / 22 = 화면 제목 |
| **U2-7** | 한 줄에 안 들어가면 **먼저 글을 줄인다.** 그래도 안 되면 `맞춤글`(자간 좁힘 → 글자 줄임). `…` 로 자르는 건 **이름에만** (10-01 홍겸 님) |
| **U2-8** | 두 줄 이상 쓸 글에는 `줄 = N` 을 **반드시** 준다. `글()` 은 기본이 한 줄이다 |
| **U2-9** | 칸 위에 붙는 작은 제목은 언제나 `이름표`. 보통 글 11sp 로 대신하지 않는다 |
| **U2-10** | **기울임(`FontStyle.Italic`)은 두 곳에만 쓴다** (2026-10-02 홍겸 님 확정). ① **플레이버 텍스트** — 업적 설명 아래 흐린 글. `11` · `옅음` · 기울임, 밑줄 없음, 누를 수 없다 ② **근거 문구** — 근거가 필요한 숫자. 기울임 **+ 밑줄**, 누르면 논문 이름 · 저자 · 연도가 뜬다 (`20_근거_빈도워밍업훈련방식.md` E-1 23번 ✅). **밑줄이 둘을 가른다** — 밑줄이 있으면 누를 수 있는 근거, 없으면 읽기만 하는 플레이버. 이 둘 밖에서는 기울임을 쓰지 않는다 |
| **U2-11** | **업적 상세는 세 줄로 쌓는다** — 업적명(`15` · Bold) → 설명(`13` · `흐림`) → 플레이버(`11` · `옅음` · 기울임). 업적명 ~ 설명 사이는 `4`, **설명 ~ 플레이버 사이는 `16`**(줄바꿈 두 번 = 한 줄 비움만큼 띄운다). 플레이버는 설명을 대체하지 않는다 (`12-5_업적칭호.md` 말투 규칙) |

## U3. 치수 · 모양

| 번호 | 규칙 |
|---|---|
| **U3-1** | 여백은 **다섯 단계뿐**: `4 · 8 · 12 · 16 · 24`. 그 사이 값(3·5·6·7·9·10·18·20·22)을 쓰지 않는다 |
| **U3-2** ★ | **화면 좌우 여백은 `12` 하나로.** 모든 탭이 같아야 탭을 옮겨도 글 시작 자리가 안 움직인다 |
| **U3-3** | 누르는 것의 높이는 **넷뿐**: `28`(칩·체크) · `32`(작은 버튼·칩) · `40`(보통 버튼·숫자칸) · `44`(큰 버튼·입력칸·목록 줄) |
| **U3-4** | 모서리는 **둘뿐**: `8`(버튼·칩·입력칸·안쪽 상자) · `16`(카드·시트). 동그란 것은 `CircleShape`. 그 밖의 값(2·3·4·6·10·12·99)을 쓰지 않는다 |
| **U3-5** | 테두리 굵기는 **둘뿐**: `1dp`(안쪽 상자·입력칸·칩·구분선) · `2dp`(카드·고정 띠·끌어 놓을 자리). `1.5` · `2.5` 를 쓰지 않는다 |
| **U3-6** | 아이콘 크기는 **둘뿐**: `18`(기본 — 아이콘버튼·펼침·−＋·›) · `16`(글 옆에 붙는 것 — 버튼 속·탭). 12·13·14·15·20 을 쓰지 않는다 |
| **U3-7** | 카드 안쪽 여백은 **둘뿐**: `14`(글이 바로 들어가는 카드) · `0`(줄마다 자기 여백을 주는 목록 카드). 10 같은 중간값을 쓰지 않는다. 기본값 14 를 다시 적지 않는다 |
| **U3-8** ★ | 진행 막대는 **하나로**: 높이 `8` · 모서리 `4` · 바탕 `면2` · 채움 `강조`. 지금 네 종류다 |
| **U3-9** | 치수도 **이름으로** 쓴다. 토큰과 값이 같으면 반드시 이름을 쓴다 (`8.dp` → `간격.좁게`) |

★ = 값을 골라야 하는 것. 지금 적힌 값은 제안이고, 한마디로 바꿀 수 있다.

## U4. 부품

| 번호 | 규칙 |
|---|---|
| **U4-1** | **같은 일을 하는 것은 같은 부품을 쓴다.** 비슷한 걸 화면에 새로 그리지 않는다 |
| **U4-2** | 새 모양이 필요하면 화면이 아니라 `ui/Common.kt`(생김새) 또는 `ui/Motion.kt`(움직이는 것)에 **부품으로** 만든다 |
| **U4-3** ★ | **하나 고르기는 `칩줄` 하나.** 지금 네 종류다. 모양이 달라야 하면 칩줄에 인자를 더하고, 새로 그리지 않는다 |
| **U4-4** | 펼치기·접기는 `펼침단추` 하나. `접기단추` 를 따로 두지 않는다 |
| **U4-5** | **한 화면 · 한 시트 안에서 버튼 높이를 섞지 않는다.** 시트의 결정 버튼은 44, 카드 안 버튼은 40, 자리 좁은 곳은 32 |
| **U4-6** | 부르는 곳이 없는 부품은 **지운다** |
| **U4-7** | 반복되는 모양이 보이면 부품을 만든다. 지금 없어서 손으로 만드는 것: **“이름 + 딸린 칩줄”**(설정 9곳) |
| **U4-8** | **시트 머리는 띠다** — 캘린더 년월 띠와 같은 값(`강조` 바탕 · `강조글` · 높이 40 · 제목 18 Bold). 오른쪽에는 `닫기` 또는 그 시트의 보조 단추 하나(띠 위 단추는 캘린더 `스탯` 칩과 같은 모양). 긴 시트에서도 머리는 위에 붙어 있다. 플랜 고치기처럼 머리 오른쪽을 보조 단추가 쓰면 `닫기` 는 아래 결정 줄로 `[저장][닫기]` (2026-10-03 홍겸 님 ✎ 표시) |
| **U4-9** | **누른 단추 바로 아래에서 고르는 짧은 것은 시트가 아니라 `단추아래팝업` 카드로 편다** (2026-10-17 홍겸 님 — 달·해 고르기가 아래에서 올라오면 손가락을 내려야 해서 비직관적). 카드 위끝 = 단추 아래 `8`, 좌우 `16`, 위끝 가운데에서 `0.9`배→`1`배로 펴지며(200ms) 뒤는 `0.35` 어둡게. 큰 상자라 `강조` 2dp 테두리 · `면` 바탕 · 모서리 `16`(U1-6 · U3-4 · U3-5). **머리 띠 · ✕ 는 없다** — 바깥을 누르거나 뒤로가기로 닫고, 고르면 바로 닫힌다. 고르는 칸이 12개 안팎이고 한 번에 하나만 고르는 것에만 쓴다. 칸이 많거나 스크롤이 필요하면 U4-8 시트를 쓴다. 지금 쓰는 곳: 캘린더 년월 띠 → 달·해 고르기 |

## U5. 동작

| 번호 | 규칙 |
|---|---|
| **U5-1** | **누르면 열린다 · 꾹 누르면 집는다** — 어디서나 같은 뜻 (동작방식 D3-9) |
| **U5-2** | 누를 때 물결(ripple)을 그리지 않는다 — `눌림()` 을 쓴다 |
| **U5-3** | 팝업·시트는 **‘고르는 일’에만.** 알리는 것은 `아래띠` 로 |
| **U5-4** | 지우기는 **묻지 않고 지우고 `아래띠` 로 되돌린다.** 되돌릴 수 없는 것만 `물음창` |
| **U5-5** | 끌고 있는 것은 투명도 `0.35`. 놓을 자리는 **가운데 = 2dp 테두리 · 위아래 = 3dp 선**. 그림자·확대는 쓰지 않는다 |
| **U5-6** | **애니메이션 중에 자리를 재지 않는다.** 멈춘 뒤 재고 한 번만 움직인다 |
| **U5-7** | **스크롤 없이 · 한 화면 안에서 · 손이 덜 움직이게.** 설명 글은 한 줄 |
| **U5-8** | 운동 중 **지금 종목 이름은 잘리면 안 된다** (두 줄까지 허용) |

## U6. 고치는 절차

1. 아티팩트에서 **번호를 집는다** (`74번`, `U2-1`)
2. 어느 규칙에 걸리는지 확인한다 — 규칙에 없는 새 값이면 **먼저 규칙을 고친다**(이 문서), 그 다음 코드
3. 값은 `Theme.kt` 에서 고친다. 화면 파일에 숫자를 새로 적지 않는다
4. 고친 뒤 `grep` 으로 바뀐 줄을 **눈으로 확인한다**
5. 커밋 전에 `watchdog` 서브에이전트를 부른다
6. **앱을 고치기 전에 아티팩트(시안)로 먼저 맞춰 본다** — 이 환경에는 Android SDK 가 없어 화면을 띄울 수 없다

## U7. 지금 Theme.kt 에 없어서 새로 만들어야 하는 이름
