# 비선형 조작 버그 목록 (2026-10-02 · 규칙 쪽)

**왜 만들었나** — 홍겸 님: *"버그들은 대부분 (예상한) 상황이 일어나지 않더라고. 화면을 왔다리 갔다리,
뒤로 갔다가 앞으로, 했다가 취소했다가. 세트를 넣었다가 뺐다가, 다섯 세트 루틴인데 뺐다가 완료했다가
다시 돌아와서 하나 더 추가하고…"* → 그런 **순서가 뒤엉킨 조작**만 노려서 찾았다.

**어떻게 찾았나** — `data/` 전부(특히 `Logic.kt` 1006줄)를 읽고, **kotlinc 2.0.21 로 직접 컴파일해 재현 탐침을 돌렸다.**
아래 **"확인"** 은 실제로 돌려 나온 출력이다. 코드만 보고 쓴 것은 `[추측]` 으로 표시했다.
⚠ **화면(ui/) 쪽은 이 문서에 없다.** 화면 흔들림·스크롤 버그는 따로 조사한다.

---

## 상 — 기록이 사라지거나, 숫자가 조용히 틀어진다

### 1. 운동 중 추가한 종목만 체크한 채 3시간이 지나면 기록을 **통째로 버린다**

- **재현**: 운동 시작 → 루틴 종목은 안 함 → `운동 추가` 로 딥스를 넣고 딥스만 체크 → 폰을 놓고 3시간
- **원인**: `Logic.kt:831` `if (S.찬세트수() == 0) return copy(세션 = null)` — `찬세트수()`(`Logic.kt:431`)가
  **정식 종목만** 세고 그 자리에서 넣은 임시 종목은 0으로 센다
- **확인**: 손으로 끝내면 `기록수=1`, 같은 세션을 자동 종료시키면 `기록수=0`.
  "손으로 끝낼 때와 같게" 라는 831줄 주석과 코드가 어긋난다

### 2. 한 종목에 세트를 더 하면 **손도 안 댄 종목까지 '달성'** 이 되고 루틴 무게가 저절로 오른다

- **재현**: 벤치 3세트 + 인클라인 3세트 루틴 → 벤치에 ＋ 로 3세트 더해 6세트를 다 체크 → 인클라인은 0세트 → 끝내기
- **원인**: `Logic.kt:428·429` `목표세트()`·`한세트수()` 가 **루틴 전체 합**이라 한 종목의 초과분이 다른 종목의 미달을 메운다
  → `Logic.kt:789` `달성 = 한세트수() >= 목표세트()` → `Logic.kt:792·843` 볼륨 자동 올리기가 **모든 종목**에 붙는다
- **확인**: `달성=true`. 한 세트도 안 한 인클라인 목표가 **40 → 41kg** 로 올랐다

### 3. 세트를 지우고 한 운동이 루틴의 **세트별 목표를 한 칸씩 밀어 올린다**

- **재현**: 세트별 목표 60/62.5/65/67.5/70 → 1세트 줄을 지움(또는 `오늘만 타이트하게`) → 2·3세트를 함 → 저장
- **원인**: `Logic.kt:882` `오늘반영` 이 **루틴 세트 번호 ↔ 기록 칸 번호**를 그대로 짝짓는다.
  줄을 지우면 기록이 한 칸 위로 올라와 엉뚱한 번호에 적힌다
- **확인**: 루틴 세트값이 `[62.5, 65, 65, 67.5, 70]` 이 됐다 — 1세트 목표가 60 → 62.5 로 뛰고 65가 두 번.
  ⚠ **다음 날 또 하면 또 오른다 (복리로 쌓인다)**

### 4. 아무 세트도 체크하지 않아도 **그 날 기록이 남는다**

- **재현**: 운동 시작 → 종목마다 `여기까지` 만 눌러 마무리 화면 → 다른 탭을 누름
- **원인**: `Logic.kt:783-789` `운동저장` 에 '찬 세트가 없으면 저장하지 않는다' 가 없다.
  `App.kt:247·292` 는 `끝화면` 이면 무조건 저장한다
- **확인**: 종목 0개인 기록이 저장된다. 게다가 `목표세트()==0` 이라 `0 >= 0` → **달성 = true**.
  달력에 '한 날' 로 찍히고 미실시·예정 순서까지 그 날 기준으로 다시 깔린다

## 중 — 달성도·목표가 틀어진다

### 5. 측정일 워밍업 줄을 지우면 목표 세트가 **늘어나** 달성이 영원히 불가능해진다

- **재현**: 측정일 운동 시작 → 워밍업 3줄 중 하나를 🗑 로 지움 → 남은 줄 전부 체크
- **원인**: `Logic.kt:428` `목표세트() = Σ(계획세트 − 웜칸수())`. `계획세트`(7)는 그대로인데
  `웜칸수()`(`Logic.kt:427`)가 3→2 로 줄어 목표가 4 → **5** 로 늘어난다
- **확인**: 남은 6줄을 다 체크해도 `달성=false · 달성도 80%`.
  덤으로 `목표볼륨()`(`Logic.kt:435-437`)이 없는 칸을 종목 기본값으로 메워 **1720 → 1805** 로 부풀었다

### 6. 체크 → 체크 풀기 를 하면 **목표가 내가 한 값으로 내려앉고 안 돌아온다**

- **재현**: 60kg×10 3세트 → 1세트를 6회로 고쳐 체크 → 체크 풀기
- **원인**: `Logic.kt:580` 체크를 풀 때 기록값을 `예정값` 에 적는다. `목표볼륨()`(`Logic.kt:437`)은 그 `예정값` 을 목표로 읽는다
- **확인**: 목표볼륨 `1800 → 1560`. 체크를 풀어도 1560 그대로. **화면의 목표 게이지가 조용히 낮아진다**

### 7. `오늘만 타이트하게` · 세트 삭제를 쓴 날은 **반드시 미달성**

- **원인**: `Logic.kt:764` `타이트하게` 는 `세트` 만 줄이고 달성의 분모인 `계획세트` 는 그대로다. `Logic.kt:713` `세트삭제` 도 같다
- **확인**: 5세트 → 타이트하게 → 4줄을 다 해도 **80%**.
  '오늘만 가볍게' 기능이 그 날을 늘 미달성으로 만들고, 볼륨 자동 올리기(성공 조건)도 영원히 안 걸린다

### 8. 순서 없이 체크 + 체크 풀기 를 되풀이하면 **세트별 계획 무게 순서가 섞인다**

- **재현**: 60/62.5/65/67.5/70 → 1세트 체크 → 4번째 줄 체크(앞으로 당겨짐) → 그 줄 체크 풀기 → 다시 4번째 체크 → 풀기
- **원인**: `Logic.kt:590·599` `당김()` 이 `예정값` 까지 함께 끌어온다. 체크를 풀어도 되돌리지 않는다
- **확인**: `60/67.5/62.5/65/70` → 한 번 더 하면 `60/65/67.5/62.5/70`. **뒤로 갈수록 무거워지는 사다리가 뒤죽박죽**

### 9. 지금 하는 줄을 지우면 '지금 세트' 가 **이미 체크한 줄**을 가리킨다

- **재현**: 1·2세트 체크 → 1세트 체크 풀기 → 그 1번 줄을 🗑 로 지움
- **원인**: `Logic.kt:716` `if (j == S.i && S.s > k) s−1` — `s == k` 면 그대로 둔다
- **확인**: `s=0` 인데 `기록[0]` 에 값이 있다. 체크 단추를 누르면 '기록' 이 아니라 '체크 풀기' 가 된다

### 10. 슈퍼세트 쉬는 중에 돌아갈 줄을 지우면 '지금 세트' 가 **허공을 가리킨다**

- **재현**: 덤벨컬 3 + 해머컬 3 슈퍼세트 → 두 바퀴 돌고 휴식 → 쉬는 동안 덤벨컬 3번째 줄 삭제 → 휴식 끝
- **원인**: `Logic.kt:677` `다음으로` → `Logic.kt:549-552` `자리로` 에 **세트 번호 범위 검사가 없다**
- **확인**: `s=2` 인데 `총칸=2`. 어느 줄도 켜지지 않고 끝화면도 아니다 (다른 줄을 누르면 스스로 낫는다)

## 따져봤지만 **괜찮았던** 것

- 체크 → 풀기 → 다시 체크 의 휴식 타이머 · 지금 세트 자리 · 기록 값 (v0.7.1 에서 고친 자리 포함)
- 쉬는 도중 다른 세트 체크 — 값이 그 줄 것으로 바르게 들어간다
- 세트 추가 → 바로 삭제 → 다시 추가 — 번호 · 값 · 휴식이 제자리로
- 마무리 화면 → 돌아가기 → 세트 추가 → 다시 끝내기 — 운동 시간이 멈춘 만큼 바르게 빠진다
- 체크 풀기로 생긴 중간 빈 칸이 저장·복원에서 보존된다
- 운동 중 종목 추가로 인한 휴식 번호 밀림

## ⚠ 시험이 비어 있다 — 이것이 뿌리다

`PlanTest.kt`(637줄) · `StatsTest.kt` · `MuscleTest.kt` 는 플랜 수학 · 측정일 워밍업 · 업적/스탯을 두껍게 덮는다.
그런데 **세션 조작을 순서대로 흔드는 시험이 하나도 없다.** 그래서 위 버그들이 전부 살아남았다.

시험이 없는 것: `체크→풀기→재체크` 되풀이 · 순서 없는 체크(당김) · `세트추가`/`세트삭제` 전부 ·
체크한 세트 삭제 · 워밍업 줄 삭제 · 슈퍼세트 뒤죽박죽 · `타이트하게` · `오늘반영` 칸 밀림 ·
임시 종목만 체크한 자동 종료 · 목표세트 0 · 빈 기록 저장

**고칠 때마다 그 조작 순서를 그대로 `PlanTest.kt` 에 시험으로 넣는다.** 안 그러면 또 되살아난다.
