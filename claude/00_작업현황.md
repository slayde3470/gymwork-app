- 사전채움판 3(처음 설치 때 미리 채워 두는 종목 묶음의 세 번째 판): 이미 채운 폰에는 유산소만 더하고, 처음 그대로인 시간 세팅은 30초로 바꾼다(지운 종목은 되살리지 않음). 새 폰은 시간 30초 · 유산소 30분
- '그날 조절'은 유산소 거리를 안 바꿈
- 달력 · 통계의 볼륨 합에서 유산소 제외
- 운동 중 타이머 — 시간(버티기): ▶ 카운트다운 → 0 이면 진동 + 자동 체크, ■ 로 일찍 멈추면 버틴 초로 체크 / 유산소: ▶ 스톱워치(휴식 칸 자리), ■ 멈추면 시간 칸에 경과 시간이 들어가고 거리는 직접 적은 뒤 체크
- 보고서: 유산소 '거리·시간' 줄, 상세에는 '5.5km · 30:00'

**확인한 방법**
- 기록방식시험 218개 · SeedTest 15개 — 컨테이너 kotlinc 로 돌려 통과
- GitHub 자동 빌드(`gradle testDebugUnitTest`) 통과
- 감시관(`watchdog`) 1번 — ⚠ 3개를 고침: ① 그날 조절이 거리를 바꿈 ② 새 종목 시트 유산소 기본이 30초가 아니었음 ③ 기존 '러닝' 이름 종목의 옛 기록이 새 방식으로 읽힐 위험은 안 고치고 대기메모로 보냄
- ⚠ 화면은 못 봤다 — 폰에서 확인 필요

**폰에서 볼 것**
1. 기본 세팅 표 / 루틴 상자에서 유산소 줄의 거리 · 시간 칸 폭
2. 운동 중 플랭크 ▶ 카운트다운 · 진동 · 자동 체크
3. 유산소 ▶ 스톱워치 → ■ → 거리 적고 체크
4. 새 종목 시트의 방식 칩 (유산소 포함)
