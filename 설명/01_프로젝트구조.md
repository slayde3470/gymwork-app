# 이 폴더에 뭐가 들어있나

코드를 못 읽어도 "어디에 뭐가 있는지"는 알 수 있게 쓴 문서.

---

## 큰 그림

```
gymwork-app/
├── app/                        ← 실제 앱
│   └── src/main/
│       ├── AndroidManifest.xml ← 안드로이드에게 앱을 소개하는 명함
│       ├── java/.../           ← 코드
│       └── res/                ← 그림, 글자, 아이콘
├── .github/workflows/          ← "코드 올리면 APK 만들어줘" 지시서
├── 문서/                        ← 무엇을 왜 만드는지
└── 설명/                        ← 이 문서. 어떻게 돌아가는지
```

## 파일 하나씩

### 앱이 켜질 때

| 파일 | 하는 일 |
|---|---|
| `AndroidManifest.xml` | 앱 이름, 아이콘, **어느 화면부터 시작할지** |
| `MainActivity.kt` | 그 "시작 화면". 앱을 켜면 여기가 제일 먼저 돈다 |

**앱을 켜면 일어나는 일**

```
아이콘 누름
  → 안드로이드가 AndroidManifest.xml 을 읽음
  → "MainActivity 부터 시작하라고 되어 있네"
  → MainActivity.kt 실행
  → 화면에 글자가 그려짐
```

### 디자인

| 파일 | 하는 일 |
|---|---|
| `ui/theme/Theme.kt` | **색 · 글자 크기 · 굵기 · 간격 · 모서리를 전부 여기서 정한다** |

**가장 중요한 파일이다.** 화면 코드에는 숫자를 직접 쓰지 않고 이 파일의 이름을 가져다 쓴다.
"글씨 좀 키워줘"는 이 파일 한 줄만 고치면 끝난다.

나중에 만들 **"앱 안에서 디자인 바꾸기"** 기능도 이 구조를 그대로 쓴다.

### 그림과 글자

| 파일 | 하는 일 |
|---|---|
| `res/values/strings.xml` | 앱 이름 (`하젠하이데`) |
| `res/drawable/ic_launcher_foreground.xml` | 앱 아이콘 — **지금은 임시 바벨 모양** |

### 빌드 (APK 만들기)

| 파일 | 하는 일 |
|---|---|
| `app/build.gradle.kts` | 패키지명, 안드로이드 버전, 쓸 라이브러리 |
| `build.gradle.kts` | 전체에서 쓰는 도구의 버전 |
| `.github/workflows/build.yml` | **코드를 올리면 GitHub이 APK를 만들게 하는 지시서** |

**APK가 만들어지는 과정**

```
Claude가 코드를 고침
  → GitHub Desktop에서 Commit → Push
  → GitHub이 build.yml 을 읽고 자동으로 빌드 시작 (몇 분)
  → Actions 탭 → 실행 기록 → 맨 아래 Artifacts 에서 APK 다운로드
  → 폰에 옮겨서 설치
```

## 지금 앱은 어디까지 되어 있나 (v0.2.0 · 2026-09-21)

**웹 시제품에서 정한 핵심을 옮긴 첫 사용판.** 기록은 **폰 안에만** 저장된다 (서버는 나중에).

| 들어 있는 것 | 아직 없는 것 (다음 판) |
|---|---|
| 캘린더 · 루틴 · 운동 실행(휴식 타이머 · 슈퍼세트) · 기록 · 종목 · 설정 · 백업 · **수정 메모** | 영양 · 신체 기록 · 성장 그래프 · 종목 사진 · 서버 · 로그인 · 화면 꺼졌을 때 알림 |

### 코드 폴더

```
app/src/main/java/com/slayde/hasenheide/
├── MainActivity.kt      ← 폰이 해 주는 일만: 진동 · 소리 · 파일 고르기 · 복사
├── data/                ← 자료와 규칙 (화면 없음 → 컴퓨터에서 따로 검사할 수 있다)
│   ├── Model.kt         ← 자료의 모양: 종목 · 루틴 · 기록 · 설정 · 운동 중 상태
│   ├── Logic.kt         ← 규칙: 2회차 미리 깔기 · 빠진 날 · 휴식 · 슈퍼세트 한 바퀴 · 향상도 · ＋ 베끼기
│   └── Storage.kt       ← 저장: 전부 JSON 파일 하나로. 같은 글자가 백업 파일이 된다
└── ui/                  ← 화면
    ├── theme/Theme.kt   ← 색 · 글자 크기 9단계 · 높이 4단계 · 모서리 (기능명세 1-2)
    ├── Icons.kt         ← 선 아이콘 한 벌
    ├── Common.kt        ← 같이 쓰는 부품: 버튼 · 칩 줄 · 숫자 버튼 줄 · 시트 · 아래 띠
    ├── App.kt           ← 전체 상태 · 아래 탭 · 되돌리기 띠
    ├── CalendarScreen.kt · RoutineScreen.kt · WorkoutScreen.kt · ExerciseScreen.kt · SettingsScreen.kt
    └── MemoSheet.kt     ← 수정 메모
```

### 자료가 흐르는 길

```
화면에서 누름
  → 상태.바꿈 { 새 앱데이터 }      ← 언제나 '새 값'을 만들어 통째로 바꾼다
  → 화면이 알아서 다시 그려진다
  → 뒤에서 조용히 hasenheide.json 에 저장 (앱 전용 폴더)
```

- 지우기는 묻지 않고 바로 하고 5초 동안 `되돌리기` — 직전 상태를 통째로 들고 있다가 되살린다
- **앱을 지우면 기록도 같이 지워진다.** 설정 → 백업 내보내기로 파일을 남겨 둘 것
