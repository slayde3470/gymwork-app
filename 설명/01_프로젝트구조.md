# 이 폴더에 뭐가 들어있나

코드를 못 읽어도 "어디에 뭐가 있는지"는 알 수 있게 쓴 문서.

---

## 큰 그림

```
gymwork-app/
├── app/                        ← 실제 앱
│   └── src/main/
│       ├── AndroidManifest.xml ← 안드로이드에게 앱을 소개하는 명함
│       ├── java/.../           ← 코드
│       └── res/                ← 그림, 글자, 아이콘
├── .github/workflows/          ← "코드 올리면 APK 만들어줘" 지시서
├── 문서/                        ← 무엇을 왜 만드는지
└── 설명/                        ← 이 문서. 어떻게 돌아가는지
```

---

## 파일 하나씩

### 앱이 켜질 때

| 파일 | 하는 일 |
|---|---|
| `AndroidManifest.xml` | 앱 이름, 아이콘, **어느 화면부터 시작할지** |
| `MainActivity.kt` | 그 "시작 화면". 앱을 켜면 여기가 제일 먼저 돈다 |

**앱을 켜면 일어나는 일**

```
아이콘 누름
  → 안드로이드가 AndroidManifest.xml 을 읽음
  → "MainActivity 부터 시작하라고 되어 있네"
  → MainActivity.kt 실행
  → 화면에 글자가 그려짐
```

### 디자인

| 파일 | 하는 일 |
|---|---|
| `ui/theme/Theme.kt` | **색 · 글자 크기 · 굵기 · 간격 · 모서리를 전부 여기서 정한다** |

**가장 중요한 파일이다.** 화면 코드에는 숫자를 직접 쓰지 않고 이 파일의 이름을 가져다 쓴다.
"글씨 좀 키워줘"는 이 파일 한 줄만 고치면 끝난다.

나중에 만들 **"앱 안에서 디자인 바꾸기"** 기능도 이 구조를 그대로 쓴다.

### 그림과 글자

| 파일 | 하는 일 |
|---|---|
| `res/values/strings.xml` | 앱 이름 (`하젠하이데`) |
| `res/drawable/ic_launcher_foreground.xml` | 앱 아이콘 — **지금은 임시 바벨 모양** |

### 빌드 (APK 만들기)

| 파일 | 하는 일 |
|---|---|
| `app/build.gradle.kts` | 패키지명, 안드로이드 버전, 쓸 라이브러리 |
| `build.gradle.kts` | 전체에서 쓰는 도구의 버전 |
| `.github/workflows/build.yml` | **코드를 올리면 GitHub이 APK를 만들게 하는 지시서** |

**APK가 만들어지는 과정**

```
Claude가 코드를 고침
  → GitHub Desktop에서 Commit → Push
  → GitHub이 build.yml 을 읽고 자동으로 빌드 시작 (몇 분)
  → Actions 탭 → 실행 기록 → 맨 아래 Artifacts 에서 APK 다운로드
  → 폰에 옮겨서 설치
```

## 지금 앱은 어디까지 되어 있나

**빌드와 설치가 되는지 확인하는 화면만 있다.** 앱 이름과 버전이 보이면 성공.

아직 없는 것: 루틴, 기록, 타이머, 로그인, 서버 연결.
무엇을 만들 것인지는 `문서/` 의 기능명세를 볼 것.
