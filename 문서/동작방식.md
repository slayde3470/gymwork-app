# 동작방식 — 앱을 만들 때 공통으로 쓰는 규칙

**갱신: 2026-09-24 (하젠하이데 v0.6.4 기준)**

이 문서는 **어느 앱에나 복사해 쓸 수 있게** 앱 고유의 내용을 빼고 적었다.
새 앱을 만들 때: "gymwork-app 저장소의 `문서/동작방식.md` 를 복사해줘" 라고 하면 된다.
(저장소는 공개라 어느 대화에서든 가져올 수 있다. 프로젝트 문서 `claude/10_동작방식.md` 에도 같은 것이 있다)

### 이 문서를 고치는 법

- 규칙마다 **번호**(예: `D3-2`)가 있다. 고칠 때는 그 번호만 고치고, 다른 곳에서는 번호로 가리킨다 → 같은 말을 두 곳에 쓰지 않는다
- 규칙 끝의 `(09-24)` 는 정한 날이다. 바뀌면 옛 규칙은 지우고 **왜 바꿨는지 한 줄**만 남긴다
- 어느 앱에서만 쓰는 값은 맨 아래 **부록**에 둔다. 본문은 앱이 바뀌어도 그대로 쓸 수 있어야 한다

## D1. 기본 원칙 — 모든 규칙보다 앞선다

| 번호 | 규칙 |
|---|---|
| D1-1 | **스크롤 없이.** 내용이 남으면 화면을 늘리지 말고 **보여 줄 것을 줄인다** (접기 · 필요한 줄만 펼치기) |
| D1-2 | **한 화면 안에서 해결.** 고치러 다른 화면으로 넘어가지 않는다. 그 줄을 펼쳐 **그 자리에서** 고친다 |
| D1-3 | **손이 덜 움직이게.** 이어서 누를 것은 방금 누른 자리 가까이. 자주 쓰는 것은 손 닿는 아래쪽, 묻는 창은 가운데 |
| D1-4 | **설명 글은 한 줄.** 기준 폭 360px. 넘치면 문장을 줄이고, 그래도 넘치면 끝을 `…` 로 자른다 (두 줄이 되면 어떤 화면도 지저분해 보인다) |
| D1-5 | **팝업은 '고르는 일'에만.** 예/아니오, 여럿 중 하나 고르기. 입력 · 확인 · 안내에는 쓰지 않는다 |
| D1-6 | 새 기능도 D1 에 맞춘다. **맞지 않으면 기능 쪽 모양을 바꾼다** |

## D2. 화면 짜임 — 통일감

| 번호 | 규칙 |
|---|---|
| D2-1 | **좌우 기준선은 화면에 하나.** 제목 · 카드 안 글 · 줄 · 아래 버튼이 모두 같은 선에서 시작하고 끝난다 (좌 16, 우 폭−16). 오른쪽 끝 아이콘 · 숫자의 끝도 같은 선 |
| D2-2 | **카드 테두리만 기준선보다 8 바깥.** 카드 안 여백은 8 |
| D2-3 | **테두리를 두 겹으로 두지 않는다.** 겹치면 그만큼 안쪽으로 밀려 줄이 어긋난다 |
| D2-4 | **크기는 정해진 단계만.** 글자 11 · 13 · 15 · 18 · 22 · 28 / 간격 4의 배수 / 높이 28(칩) · 32(작은 버튼) · 40(버튼 · 입력 · 값 줄) · 44(목록 줄) · 52(아래 탭) / 모서리 8 · 12 · 16 · 동그라미 |
| D2-5 | 색 · 글자 · 간격은 **한 파일**(테마)에 모은다. 화면 코드에 숫자를 직접 쓰지 않는다 |
| D2-6 | **색은 뜻이 하나.** 강조색 = 누를 것 · 지금 · 완료 / 다른 한 색 = 묶음(예: 슈퍼세트) / 빨강 ▲ 파랑 ▼ = 늘고 줄어듦(숫자에만) |
| D2-7 | **아이콘은 선 아이콘 한 벌.** 이모지 · 글자 기호(⚙ ∨ ✕ 🗑)를 섞지 않는다. 같은 뜻은 어디서나 같은 아이콘 |
| D2-8 | 칩 줄은 **한 줄**, 넘치면 옆으로 밀기. 오른쪽 끝을 흐리게 해 더 있다는 것을 알린다 |
| D2-9 | 이름 옆 부가 정보(분류 등)는 **아래 줄이 아니라 바로 옆**에 흐린 작은 글씨로. 단, 이름이 잘릴 만큼 정보가 많으면 정보를 아랫줄로 (이름이 먼저) |
| D2-10 | **요약 판에는 요약만.** 이름 · 한 줄 요약 · 향상도 · 버튼. 세부 목록(세트 나열 등)을 넣어 판이 넘치면 버튼이 가려진다 (09-24) |

## D3. 조작 문법 — 어디서나 같은 뜻

| 번호 | 동작 | 뜻 |
|---|---|---|
| D3-1 | 누르고 떼기 | 열기 · 고치기 · 고르기 |
| D3-2 | 꾹 누르기(0.5초) | **집어서 옮기기** 하나만. 누르고 떼기와 뜻을 겹치지 않는다 (겹치면 헷갈린다). 0.15초 뒤부터 테두리, 손가락이 12px 넘게 움직이면 스크롤로 보고 취소 |
| D3-3 | 아래 화살표 ∨ | 펼치기. 열리면 뒤집힌다. **펼치기가 있으면 접기도 반드시 있다** |
| D3-4 | 지우기 | **묻지 않고 바로 지우고, 5초 동안 `되돌리기` 띠.** 되돌리기 띠는 시트보다 위에 (시트에 가려지면 안 된다) |
| D3-5 | 마지막 하나를 지울 때 | 그것이 사라지면 묶음 전체가 없어지는 경우만 가운데 창으로 묻는다 (D1-5 의 '고르는 일') |
| D3-6 | 뒤로가기 | 안에서 바깥으로 한 겹씩: 입력 중 → 자판 내림 → 입력 닫기 / 시트 → 닫기 / 펼친 칸 → 접기 / 다른 탭 → 첫 화면 / 첫 화면 → 앱 나가기 |
| D3-7 | 빈 곳 누르기 | 열린 입력칸 · 시트를 닫는다 (값은 D4 규칙대로) |

## D4. 숫자 · 글 입력

| 번호 | 규칙 |
|---|---|
| D4-1 | 숫자는 평소 **값만** 보이고, 누르면 그 칸이 넓어지며 좌우에 **− ＋** |
| D4-2 | **− ＋ 로 바꾼 값은 누른 순간 확정.** 빈 곳 · 뒤로가기로도 되돌아가지 않는다 (09-24: '취소' 개념을 없앴다 — 무엇이 취소되는지 헷갈렸다) |
| D4-3 | **자판으로 친 값은 '완료'를 안 눌러도** 칸이 닫히며 들어간다. 치는 순간 옛 값은 지워지고, 안 치면 그대로 |
| D4-4 | **휠은 돌려도 값이 안 바뀐다. 숫자를 눌러야** 들어가고 칸이 닫힌다 (돌리다 멈춘 값이 들어가 버리던 것) |
| D4-5 | 휠은 **누른 칸 바로 아래, 그 칸 폭으로**. 휠을 만지면 자판은 내려간다. 휠을 끄는 동안 화면은 고정 |
| D4-6 | 개수(세트 수 등)처럼 작은 정수는 **− ＋ 만** (휠 · 직접 입력 없음). ＋ 는 **누른 줄을 베껴 바로 아래에** |
| D4-7 | 시간은 `분 : 초` 두 칸. 초 칸에 치기 시작하면 분 칸을 비워 `1:60` 같은 중간 모양이 안 보이게 |
| D4-8 | 자판 · 휠이 떠 있으면 **아래 탭을 숨긴다**. 입력칸이 자판에 가려지면 **열릴 때 화면을 끌어올린다** |
| D4-9 | **긴 글은 여러 줄 칸으로 고친다.** 한 줄 칸이면 가로로 찾아야 한다 (09-24) |
| D4-10 | 이름을 치면 **추천 목록** — 자음 · 모음 단위, 띄어쓰기 무시. 하나를 고르면 목록을 닫고, 다시 고치면 또 뜬다 |

## D5. 화면의 움직임 — 저절로 움직일 때

| 번호 | 규칙 |
|---|---|
| D5-1 | **자동 스크롤은 필요한 때만.** 평범한 목록은 봐야 할 줄이 화면 밖으로 나갈 때만, 들어올 만큼만. 단 **고정 띠가 있는 진행 화면**(D5-5)은 매 단계 기준 줄을 띠 바로 아래로 올린다 |
| D5-2 | **자리를 재는 것은 애니메이션이 멈춘 뒤.** 접히는 중에 재면 멈춘 뒤 자리가 달라져 겹친다 (09-24: 고정 띠 밑으로 첫 줄이 파고들던 원인) → 짧게 여러 번 재어 **두 번 연속 같으면** 그때 움직인다 |
| D5-3 | **화면을 움직이는 곳은 하나로.** 두 곳이 따로 스크롤하면 서로 부딪친다 |
| D5-4 | **'무엇이 바뀌었을 때' 움직일지를 정확히.** 같은 묶음 안에서 오가는 것(예: 슈퍼세트 A↔B)은 '묶음이 바뀐 것'이 아니다 (09-24: 오갈 때마다 다시 맞춰 상자가 밀렸다) |
| D5-5 | **지금 하는 것은 맨 위에 고정 띠로.** 목록은 그 뒤로 지나가고, 끝낸 것은 띠 뒤로 가려진다. 띠에는 **지금 할 것 하나만** 한 줄로 (묶음이면 `슈퍼세트 A 해머 컬` 처럼, 쉬는 동안이면 다음에 할 것). 목록 안의 지금 묶음은 머리를 그리지 않는다 — 같은 이름이 두 번 나오지 않게 (09-24) |
| D5-5-1 | **기준 줄**(쉬는 중이면 휴식이 도는 줄, 아니면 지금 할 줄)을 체크 · 휴식 · 이동마다 **띠 바로 아래로** 올린다. 끝낸 줄은 띠 뒤로 잘리고 아래 줄이 올라온다 (09-24) |
| D5-5-2 | 목록 끝에 **빈자리**를 둔다 — 마지막 항목이어도 기준 줄을 띠 아래까지 올릴 수 있을 만큼만. 없으면 끝낸 항목이 띠 아래에 남는다 (09-24) |
| D5-6 | 펼쳐 둔 지난 것은 **절반쯤 화면을 벗어나면** 저절로 접는다. 지금 것은 접지 않는다 |
| D5-7 | 누른 것에 대한 반응은 **즉시.** 두 번 누르기를 기다리느라 한 번 누름을 늦추지 않는다 |
| D5-8 | 사라지는 것은 애니메이션 없이 바로 (지운 줄 등). 펼치고 접는 것만 부드럽게 |

## D6. 수정 메모 — 써보면서 고칠 점을 모으는 장치

앱을 직접 쓰면서 고칠 점을 바로 적고, 모아서 Claude 에 붙여넣는 통로다. **새 앱에도 처음부터 넣는다.**

| 번호 | 규칙 |
|---|---|
| D6-1 | 아래 탭 맨 오른쪽에 `메모`. 어느 화면에서든 연다. 메모에 **어느 화면에서 적었는지**가 붙는다 |
| D6-2 | **직전 동작 10가지**가 함께 저장된다 (탭 이동 · 칸 누름 · − ＋ · 입력 · 체크 · 이동 · 접기 …). 이어지는 동작(자판 입력)은 시작–끝을 한 번으로. 값(무게 등)까지 적는다 |
| D6-3 | `전부 복사` → 메모마다 `- [화면] 글` 아래에 직전 동작을 들여쓰기로 붙인 글 |
| D6-4 | **쓰던 메모는 시트를 닫아도 남는다.** 화면을 확인하러 닫았다 다시 열면 이어서 쓴다 (앱을 완전히 끄면 사라진다) (09-24) |
| D6-5 | 목록의 메모는 **누르면 전체가 펼쳐지고, 다시 누르면 접힌다** (09-24) |
| D6-6 | ✎ 로 **그 자리에서 여러 줄로** 고친다 (D4-9) |
| D6-7 | 지우기는 D3-4 (되돌리기) |
| D6-8 | **백업 파일에는 메모를 넣지 않는다.** 백업을 가져올 때 파일에 메모가 없으면 폰의 메모를 그대로 둔다 (09-24) |

## D7. 저장

| 번호 | 규칙 |
|---|---|
| D7-1 | 처음엔 **폰 안 파일 하나**(JSON). 서버는 나중에 |
| D7-2 | 파일에 **스키마 번호**. 구조를 바꾸면 올리고, 옛 번호의 파일도 읽히게 옮기는 코드를 둔다 (시험으로 확인) |
| D7-3 | 쓸 때는 **임시 파일에 쓰고 바꿔치기** — 쓰다 멈춰도 원본이 남는다 |
| D7-4 | 설정에 **백업 내보내기 / 가져오기**. 앱을 지우면 폰 안 기록도 지워진다는 것을 한 줄로 알린다 |
| D7-5 | 서버를 붙일 때를 대비해 기록마다 ID · 만든 때 · 고친 때 · 사용자 · 지움 표시 |

## D8. 만드는 방식 — Claude 와 일할 때

| 번호 | 규칙 |
|---|---|
| D8-1 | **화면을 바꿀 때는 앱보다 먼저 시안(아티팩트)** 으로 맞춰 본다 |
| D8-2 | **시킨 것보다 더 바꾸지 않는다.** 한 칸을 바꾸라면 한 칸만 |
| D8-3 | 메모를 받으면 **먼저 분류해 보여 주고, 애매한 것만 묻는다.** 한꺼번에 받은 일은 도중에 멈추지 않고 끝까지 |
| D8-4 | 파일을 고친 뒤 **grep 으로 바뀐 줄을 확인**하고 올린다 (쓰다 멈춘 파일이 빠진 채 올라간 적이 있다) |
| D8-5 | **확인하지 않은 것을 '완료'라고 하지 않는다.** 무엇으로 확인했는지(시험 · 빌드 · 폰) 함께 적는다 |
| D8-6 | 규칙(계산 · 저장)은 화면과 떼어 두고 **시험 코드**로 돌린다. 화면은 폰에서만 알 수 있다 |
| D8-7 | 설명할 때 **'어떻게 보이는지'와 '속으로 어떻게 도는지'** 를 나눈다. 모르면 모른다, 추측이면 추측이라고 |
| D8-8 | 여러 번 말하지 않은 요구는 붙들고 있지 않는다 (한 번 말한 것이 잘 안 됐는데 다시 말하지 않으면 지운다) |

## D9. 교훈 — 같은 실수를 막으려고

- **누르고 있는 동안 그 칸을 다시 그리지 않는다** — 폰은 이후 터치를 처음 누른 칸으로만 보낸다. 칸이 다시 그려지면 끌기가 죽는다
- **꾹 눌러 끄는 동작은 언제든 취소될 수 있다고 보고 만든다** — 취소되면 아무 일도 없게
- **이름을 새로 지을 때 이미 있는지 먼저 찾는다** — 화면 이름 · 부품 이름 · 함수 이름이 부딪쳐 세 번 고장 났다
- **'안 된다'는 보고를 받으면 검사 도구보다 코드를 먼저 의심한다**
- **전역 상태를 여러 줄이 함께 보고 있으면** 하나를 바꿀 때 모두가 움직인다 → '그 줄에 실제로 열린 것이 있을 때만' 반응하게 (화면 떨림의 원인이었다)
- **애니메이션 중에 자리를 재지 않는다** (D5-2)
