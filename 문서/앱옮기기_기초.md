**공용 파일**(`data/**` · `ui/App.kt` · `ui/Common.kt` · `ui/Parts.kt` · `ui/Icons.kt` · `ui/theme/Theme.kt` · `MainActivity.kt`)은
고치지 않는다. 꼭 필요하면 보고에 "공용 고칠 것" 으로 적는다 → 합칠 때 한 사람이 고친다.
순수 계산이 새로 필요하면 자기 화면 파일 안에 `internal fun` 으로 두고 보고에 적는다(합칠 때 data/ 로 옮긴다).

### 같이 쓰는 함수 — 매개변수를 바꾸지 않는다
- `종목넣기시트(상태, 제목, 개수, 넣기, 빼기, 닫기, 새종목만들기=true)` — 틀은 1단계에 있다. 속은 RT 가 채우고 W 는 부르기만
- `새종목시트(상태, 닫기, 저장={}, 편집=null, 처음이름="")` — 틀은 1단계에 있다. 속은 EX 가 채우고 RT · W 는 부르기만
- 다른 파일이 부르는 기존 함수(예: ExerciseScreen 의 `종목이름칸` · `부위고르기` · `장비고르기` · `목표칸`, RoutineScreen 의 `펼침단추` · `조사`)는
  **이름 · 매개변수를 지키고**, 새 매개변수는 기본값으로만 단다. 안 쓰게 됐어도 지우지 않는다(합칠 때 지운다)

### 결과 화면 경계 (W ↔ R)
- `ReportScreen.kt`: `결과화면(상태, S)` · `마무리(상태, S, 저장됨)`(internal) · 종목그래프 · 선그림 · 증감표 · 시계글
- `WorkoutScreen.kt`: `운동화면(상태, 폰)` 과 그 밖의 운동 중 부품 전부 (`루틴표시` 는 여기 · 공용)

**시트** (`Common.kt` `시트(제목, onClose, 위끝고정=false, content)`): 모든 시트에 손잡이 막대 36×4 가 저절로 붙는다.
손잡이 · 제목 줄을 잡고 80dp 넘게 끌어내리면 닫힌다(덜 끌면 제자리). 시트 안 스크롤과는 겹치지 않는다.
`위끝고정 = true` 면 위끝이 화면 높이 20% 자리에 고정(종목 넣기 · 새 종목 시트).

`칩줄(…, 밖넘김: ScrollState? = null)` — 밖에서 넘김을 쥘 때(화살칩줄이 쓴다). `맞춤글(…, 굵기)` 매개변수가 늘었다.

**Theme 토큰**: 색 `완료바탕` · `지금깜빡` · `노랑` · `노랑테` (밝음/어두움 둘 다) · 치수 `부품치수.*` (손잡이 · 칩화살 · 값칸단추 · 딱지 · 끌기 · 노란점 · 당김 · 토스트 · 탭) ·
`휴식칸값` · `이름맞춤값` · `움직임.*` 시간 값. **Color 를 직접 쓰지 않는다.**

**아이콘** (`ui/Icons.kt`): 돋보기 · 북마크 · 카메라 · 공유 · 링크 · 핀 · 톱니(진짜) · 사람 · 프로필사람 · 돌림 · 칩화살.

## 4. 데이터 (스키마 15 · `data/`)

옛 14 이하 JSON 은 그대로 열린다(빠진 필드는 기본값). 기존 필드 이름 · 타입은 바꾸지 않았다(추가만).

### 새 필드
| 어디 | 필드 | 타입 · 기본값 | 뜻 |
|---|---|---|---|
| 종목 | `id` | String · = 이름 | 같은 이름 종목 허용. 옛 종목은 이름이 id. 읽을 때 id 가 겹치면 뒤의 것을 "벤치프레스-2" 로 |
| 종목 | `근육` | Map<String,String> · {} | 세부 부위 id → "P" 주동 / "Y" 협응. 옛 "S" 는 읽을 때 "Y". 비면 내장 규칙 |

| 루틴종목 · 세션종목 · 종목기록 | `종id` | String? · null | null = 옛 줄 → 이름으로 찾는다 |
| 설정값 | `닉네임` | "" | 12자까지 (`닉네임최대`) |

### 열쇠 규칙
- **종목설정 열쇠 = 종목.id** (옛 종목은 이름)
- **줄의 열쇠** = `종id ?: 이름` (`종목열쇠(종id, 이름)` · 줄의 `.열쇠`)
- **종목 찾기** `d.종목찾기(종id, 이름)` — 종id 먼저, 없거나 못 찾으면 이름(같은 이름 여럿이면 앞의 것). `종목찾기(열쇠)` 도 있다
- 새 종목은 `d.종목더하기(e, 세트?)` — id 가 겹치면 새 id (`새종목id()`)
- 운동 시작 · 저장은 종id 를 그대로 넘긴다. `오늘반영` 은 열쇠로 짝짓는다

### 새 함수 (Logic.kt)
- `같은이름번호(종목표, 열쇠, 이름)` / `d.같은이름번호(종id, 이름)` → 딱지 번호(하나뿐이면 0)
- `d.종목기본세트(열쇠)` — 종목설정, 없으면 설정 기본 세트 수 × 20kg · 10회 · 기본 휴식 · `옛종목설정(…)` · `종목세트최대 = 10`
- `d.루틴줄(열쇠)` / `d.세션줄(열쇠, 임시=true)` — 기본 세팅으로 만든 줄(종id 포함)
- `링크주소(v)` · `인증순(l)` · `d.인증넣기(파일, 때)`(8장 넘으면 null) · `d.인증고정(파일, 지금)`(3장 넘으면 null)
- `큰운동표` · `큰운동추가정리(l)`
- `d.업적보임(번호)` · `업적보임바꿈` · `업적차례(칭호?)` · `업적옮기기(원, 대상, 뒤에)` (정렬이 "직접" 으로)
- `목옮김(l, 원, 대상, 뒤에)` — 시안 끌기 `옮김` 과 같다
- **운동 중 순서** — 결과 `운동자리(세션, 본, 자리표)` (자리표 = 옛 번호 → 새 번호, 빠진 칸은 null. 접힘 같은 화면 상태를 옮길 때)
  - `S.종목빼기(j, 본)` → `Pair<운동자리, 뺀종목>?` (하나만 남았으면 null). 화면은 `뺀종목` 을 들고 있다가 [되돌리기] 에 넘긴다
  - `S.종목되돌리기(뺀종목, 본, 지금)` — 빼기 → 되돌리기 = 원래 세션
  - `S.종목옮기기(원, 대상, 뒤에, 본)` — 끌기. 지금 · 휴식 · 다음i · 본이 같은 종목을 계속 가리킨다
  - `S.종목넣기(e, 본)` — 맨 끝에([＋])
  - `S.넣은것빼기(본) { 맞음 }` — 넣기 시트 누름 = 맨 뒤부터 하나 뺀다(한 것 · 지금 · 쉬는 중은 건너뜀)

### 근육 · 사전
- `d.종목근육(종id, 이름)` — 사용자 역할 먼저, 없으면 내장 규칙. `근육채움` · `근육단계` · `피로쌓기` 가 이것을 쓴다
- 내장 `MuscleData` 의 보조근 "S"(비중 0.5)는 그대로 (홍겸 님께 물을 것)
- `종목사전.목록` 129개 (`사전종목(이름, 칸, 별, 근)`) · `종목사전.찾기(q, 종목표, 최대=8)` 초성 검색(초성 · 글자 섞기 · 띄어쓰기 무시 · 다른 이름 · 치는 중 받침) · `정확히` · `이름으로` · `초성` · `세부부위` · `둘역할`(S·Y → Y)
