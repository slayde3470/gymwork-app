# 클로드코드로 이사 — 준비 목록 (2026-10-25)

> claude.ai 프로젝트 '운동어플' → 클로드코드(claude.ai/code · Claude 앱의 Code 탭)로 주 작업 공간을 옮긴다.
> 프로젝트는 없어지지 않는다. 이사가 끝나면 **설계 문서의 정답은 저장소 `claude/` 폴더 하나**다.

## 2. 해 둔 것 (2026-10-25 · claude.ai 프로젝트 대화에서)

- `claude/` 에 프로젝트 문서 17개를 **이름 그대로** 복사 — 그래서 CLAUDE.md 가 말하는 `claude/00_색인.md` 가 이제 저장소 파일 경로이기도 하다. 복사 방법: `project_read` 결과를 그대로 파일로 (손으로 옮겨 적지 않음)
- `claude/프로젝트지침.md` — 프로젝트 지침 원문
- `claude/기억_작업방식.md` — 기억 중 작업 규칙 · 앱 방향
- ⚠ 복사한 문서 중 `00_작업현황.md` 는 **10-05 판**이다. 그 뒤 일은 `문서/작업일지.md` (152) ~ (155) 등에 있다 — 이사 뒤 첫 "정리해" 때 합친다

## 3. 홍겸 님이 할 것 (순서대로)

1. **올리기 허락** — 위 파일들을 GitHub 에 올리는 것 (이 대화에서 답)
2. **claude.ai/code 열기 → GitHub 연결** — Claude GitHub App 을 설치하고 `gymwork-app` 을 고른다. 환경은 처음 만들어 주는 Default 그대로
3. **CLAUDE.md 고치기 허락** — 4절 목록. 허락 전에는 Claude 가 고치지 않는다
4. **첫 세션 시험** — 클로드코드에서 이렇게 말해 본다: `CLAUDE.md 읽고, 아티팩트 도구가 있는지랑 main 최신 빌드 결과 알려줘`
5. 이사 뒤에는 **프로젝트 문서를 더 고치지 않는다** — 두 곳을 고치면 서로 어긋난다

## 4. CLAUDE.md 고칠 곳 — 2026-10-25 고침 (홍겸 님 "고쳐")

1~5 는 고쳤다. 6 · 7 은 클로드코드에서 확인해야 해서 CLAUDE.md 에 "⚠ 첫 세션에서 확인" 표시만 넣었다. `.claude/agents/docwriter.md` 도 `claude/` 폴더를 고치도록 바꿨다.


1. 1절 1·2번 `add_repo` · `git clone` → "저장소는 세션이 열어 둔다. `git fetch origin main` 부터"
2. 2절 "설계 문서는 claude.ai 프로젝트에 있다 · `project_read`" → "저장소 `claude/` 폴더 · `Read` · `Grep` 으로"
3. 2절 "저장소 문서는 낡았을 수 있다 · 프로젝트 문서가 우선" → "`claude/` 가 정답"
4. 프로젝트 지침의 [빠른 길] · [시안] 을 CLAUDE.md 에 합치기 (지금은 지침이 CLAUDE.md 보다 우선이라 따로 있다)
5. `claude/기억_작업방식.md` 를 CLAUDE.md 에서 가리키기 (클로드코드에는 프로젝트 기억이 없다)
6. 2-1 ✎ 표시 · 아티팩트 → 첫 세션 확인 결과대로
7. 1절 '이 환경의 제약' (Maven 403 · kotlinc · SDK 없음) → 새 환경에서 다시 확인해 고침

- 폰에서는 Claude 앱의 **Code 탭**으로 같은 세션을 이어 볼 수 있다
- 세션은 창을 닫아도 클라우드에서 계속 돈다
