# 근육그림 — 1차 (2026-10-09)

제미나이 회색 근육 밑그림 6장 → 다듬은 그림 + 색칠 지도. 다음: 2차 = 색 입히는 방식 시안 3~4가지 → 3차 = 앱 반영.

| 폴더 · 파일 | 무엇 |
|---|---|

## 다시 만들기
```
python3 다듬기.py            # 원본 → 그림
python3 지도도구.py 색표      # 근육 나무가 바뀌었을 때만
python3 지도도구.py 그리기    # 경계 → 지도 · 확인 (경계를 그림의 근육 골로 붙임 · 손질/ 이 있으면 그것)
```

## 손질 도구에서 저장한 것 옮기기 (Claude 가 할 일)
1. `ArtifactData` `list` — url 위 주소, collection `edits`, `out_dir` 로 받기. 문서 id: front · back · chest · arm · leg · upback (= 01 ~ 06), `확인: false` 가 새 손질
2. `python3 지도도구.py 가져오기 01_전신앞 받은파일.json` → 검사 통과하면 `손질/` 에 들이고 지도 · 확인 사진을 다시 그림
3. 확인 사진을 보고 → 그 문서를 `update` 로 `확인: true` → 아티팩트를 다시 올려 새 지도(map/)를 바탕으로 쓰게 한다

## 정한 것
- **쪽**: 전신 01 · 02 만 좌우를 나눈다. `L` = 사람의 왼쪽(앞모습에서는 그림 오른쪽, 뒷모습에서는 그림 왼쪽). ⚠ 지금 앱 SVG(`hasenheide-body.svg`)는 앞 · 뒤 모두 '그림 왼쪽 = L' 이라 뜻이 다르다 — 앱에 넣을 때 맞출 것
- 그림에 또렷하게 보이는 만큼만 나눴다. 가슴은 전신에서 `pectoralis_major` 하나, 가슴 확대에서만 위 · 가운데 · 아래
- 머리 · 손 · 발 · 무릎 · 목 앞 가운데 · 사타구니는 근육이 아니라 투명

## 짐작한 곳 (경계가 흐려 해부 위치로 정함)

### 01_전신앞
- 전거근 (`serratus` · 좌우 둘 다) — 가슴 아래 옆구리 톱니 — 그림에 흐릿하게만 보임
- 어깨 앞 (`delt_front` · 좌우 둘 다) — 어깨 앞 · 옆 경계 — 그림에 선이 없어 가슴 쪽 절반을 앞으로 나눔
- 흉쇄유돌근 (`scm` · 좌우 둘 다) — 목 앞 비스듬한 근육 — 목 옆 그늘을 따라 짐작
- 삼두 (상완삼두근) (`triceps` · 좌우 둘 다) — 팔 바깥 띠 — 앞에서 보이는 삼두 가쪽
- 상완근 (`brachialis` · 좌우 둘 다) — 팔꿈치 위 바깥 — 이두와 삼두 사이
- 완요골근 (`brachioradialis` · 좌우 둘 다) — 아래팔 위쪽 앞 불룩한 곳 — 손목 굽힘·폄 근육은 나누지 않고 '전완'으로
- 허벅지 안쪽 (내전근) (`adductors` · 좌우 둘 다) — 허벅지 안쪽 위 — 모음근 무리로 묶음
- 봉공근 (`sartorius` · 좌우 둘 다) — 엉덩이뼈 앞에서 무릎 안쪽으로 비스듬한 띠 — 그림의 비스듬한 홈을 따라
- 대퇴근막장근 (`tfl` · 좌우 둘 다) — 엉덩이 옆 앞 — 넙다리근막긴장근
- 비골근 (`peroneus` · 좌우 둘 다) — 정강이 바깥 띠
- 비복근 안쪽갈래 (`gastrocnemius_medial` · 좌우 둘 다) — 종아리 안쪽 불룩한 곳(앞에서 보임)
- 가자미근 (`soleus` · 좌우 둘 다) — 종아리 안쪽 아래 — 가자미근
