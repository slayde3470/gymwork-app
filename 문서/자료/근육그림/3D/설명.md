# 근육그림 3D (2026-10-09)

3D 근육 모형을 블렌더로 찍어 만든 회색 클레이 그림 6장 + 근육별 단색 지도 6장. **앱에는 아직 넣지 않았다.**
1차(제미나이 밑그림 + 손으로 그은 경계, 위 폴더 `그림/` · `지도/` · `경계/`)는 그대로 두었다.

지도의 경계는 손으로 긋지 않는다 — 모형의 근육 조각(218개)이 화면에 찍힌 자리 그대로다.

## 폴더

| 폴더 · 파일 | 무엇 |
|---|---|
| `그림/` | 회색 클레이 그림 6장. 배경 투명. 01 · 02 는 768×1376 (머리 끝 y20 · 발끝 y1355 · 가운데 x383 — 1차와 같은 자리), 03 ~ 06 은 1024×1024 |
| `지도/` | 색칠 지도 — 그림과 같은 크기. 근육 하나에 단색 하나(테두리 섞임 없음). 색은 `../색표.json` |
| `확인/` | 그림 + 지도 겹친 사진(경계선 · 이름표) — `../지도도구.py` 의 겹쳐보기 |
| `대응표.json` | 모형의 근육 이름(109가지) → 근육 나무 id (`../../근육지도/muscle-catalog.json`). 짐작 · 비움 · 주의도 여기 |
| `찍기.py` | 블렌더 안에서 도는 스크립트: 모형 → `찍은것/` (클레이 그림 + 조각 번호 그림). 구도 · 빛 · 굽힘 각도는 파일 위쪽 표 |
| `지도만들기.py` | `찍은것/` → `그림/` · `지도/` · `확인/` + 검사. 블렌더 없이 돈다 |
| `찍은것/` | 찍기.py 가 낸 중간 결과. 이것만 있으면 블렌더 없는 곳(클라우드)에서도 지도를 다시 만들 수 있다 |
| `모형/` | 남자 모형 GLB(2.5MB) + 출처 글 |

## 다시 만들기 (이 폴더에서)
```
"C:\Program Files\Blender Foundation\Blender 4.5\blender.exe" --background --factory-startup --python 찍기.py -- 모형/full-body-male-mobile.glb 찍은것
python 지도만들기.py
```
- 블렌더 4.5.10 LTS · 6장에 약 6분 (RTX 4070 Ti SUPER). 한 장만: 끝에 번호 (`… 찍은것 05` · `python 지도만들기.py 05`)
- 파이썬 부품: numpy · opencv-python · pillow · scikit-image
- 대응표만 고쳤으면 `지도만들기.py` 만 다시 돌리면 된다

## 정한 것
- **체형은 모형 그대로** — 평균 체형 해부 모형이라 1차 그림(보디빌더)보다 마르다. 피부 없이 근육 · 힘줄 · 뼈가 드러난다 (10-09 홍겸 님 확인: "일단 계속")
- **쪽**: 전신 01 · 02 만 좌우를 나눈다. `L` = 사람의 왼쪽 (모형의 +X). 확대 03 ~ 06 은 쪽 없음
- **근육 id 는 근육 나무의 가장 잔 것**으로 넣었다 (전신에서도 가슴 위 · 가운데 · 아래, 이두 긴 · 짧은갈래 …). 1차는 전신에서 `pectoralis_major` 하나였다 — 묶어 쓰려면 나무의 parent 로 올라가면 된다
- **구도**: 03 가슴 = 사람의 왼쪽 앞 45°, 04 팔~어깨 = 왼팔 · 왼쪽 앞 55°(팔은 내린 자세 그대로), 05 = 오른 다리를 굽힌 옆 · 뒤, 06 = 등
- 머리 · 손 · 발 · 뼈 · 힘줄은 근육이 아니라 투명. 목 앞을 덮는 넓은목근은 흉쇄유돌근 · 승모근을 가려서 모형에서 지웠다

## 짐작 · 손본 곳 (틀릴 수 있다)
- **복근 위 · 아래**: 모형의 복직근은 한 덩어리 → 높이 1.015m(키 1.708m)에서 잘랐다. 배꼽 높이는 짐작
- **복근이 보이게**: 모형에서는 외복사근의 널힘줄(얇은 막)이 복직근을 덮고 있다 → 지도에서는 그 자리를 복직근으로 칠했다 (그림에는 막이 덮인 채로 찍힌다)
- **힘줄 · 근막 아래**: 막 바로 아래가 근육이면 그 근육으로 칠했다 (장경인대 아래 외측광근, 허리 근막 아래 기립근 …)
- **승모근 위 · 아래**: 모형에서 이름과 자리가 뒤바뀌어 있어 자리를 보고 바꿔 넣었다 (`대응표.json` 주의). 나머지 조각은 자리를 재서 이름과 맞는 것을 확인
- **근육 나무에 없는 근육**: 긴엄지발가락폄근 → `shin`, 종아리 깊은 굽힘근 · 오금근 · 장딴지빗근 → `calves` (묶음 id). 위 · 아래 뒤톱니근은 비움
- **05 굽힌 다리**: 모형에 뼈대(관절)가 없어 꼭짓점을 직접 돌렸다 (엉덩관절 62° · 무릎 88°). 사타구니 · 무릎 둘레는 근육이 벌어지거나 겹쳐 실제와 다르다. 다리를 가리는 두 팔은 지웠다
- 뒤에서 본 그림에 다리 사이로 앞쪽 근육(복근 아래 · 대퇴직근)이 조금 비친다 — 모형 그대로
