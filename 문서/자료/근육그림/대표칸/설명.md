# 대표칸 — 제미나이 그림 위 15칸 지도 (2026-10-09)

사람들이 주로 노리는 근육 **15칸**만 칠하는 지도. 그림은 제미나이 그림 6장(`../그림/`)을 그대로 쓴다.

| 파일 · 폴더 | 무엇 |
|---|---|
| `칸표.json` | 15칸 정의 — 칸 이름 · 지도에 칠하는 대표 색의 근육 id · 그 칸에 들어가는 근육 |
| `고칠곳.json` | 그림마다 경계를 손본 목록(좌표). **경계를 고칠 때는 여기를 고친다** |
| `다듬기.py` | 1차 지도(`../지도/`)를 15칸으로 묶고 → 고칠곳을 적용하고 → 경계를 매끈한 곡선으로 → `지도/` · `확인/` · `보기/` |
| `밑그림/` | 선을 그을 때 쓰는 회색 그림(흰 바탕) 6장 |
| `손선뽑기.py` · `손선/` | 홍겸 님이 그림 위에 그어 준 선을 뽑아 원래 그림 자리에 맞춘 것. 있으면 다듬기.py 가 그 선으로 나뉜 조각마다 한 칸으로 정한다(선 자체는 매끈하게 다시 편다 · 전신은 좌우를 맞춘다). 지금은 01_전신앞만 있다 |
| `묶기.py` | 잔 근육 지도를 15칸으로 묶는 부분(다듬기.py 가 불러 쓴다) |
| `지도/` | 색칠 지도 — 칸 하나에 단색 하나(테두리 섞임 없음). 색 → 칸은 `칸표.json` 의 대표 id 와 `../색표.json` |
| `확인/` | 그림 + 지도 + 경계선 · 이름표 |
| `보기/` | 명암을 살려 색을 입힌 모습(앱에서 보일 느낌) |
| `프롬프트.md` | 제미나이에 새 그림을 받을 때 쓸 글(지금은 쓰지 않음) |

다시 만들기: `python 다듬기.py` (한 장만: `python 다듬기.py 06`)

## 정한 것 (홍겸 님 · 10-09)
- 15칸: 목 · 어깨 · 가슴 · 광배 · 승모 · 허리 · 이두 · 삼두 · 전완 · 복부 · 엉덩이 · 대퇴사두 · 햄스트링 · 내전근 · 종아리
- **칸에는 그 근육 자리만 칠한다.** 엉덩이 = 엉덩이 근육 둥근 덩어리만 — 옆으로 삐져나온 살 · 엉덩이골 위 · 앞에서 보이는 골반 옆은 칠하지 않는다
- 대원근 → 광배, 상완근 → 이두, 상완요골근 → 전완, 정강이(전경골근) → 종아리, 목은 목 전체
