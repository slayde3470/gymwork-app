## 2. 루틴 · 숫자 입력

- 숫자 칸을 누르면 **자판과 휠이 같이** 뜬다. 휠을 만지면 자판이 내려간다
- **휠은 돌려도 값이 안 바뀐다.** 가운데 숫자를 **눌러야** 들어간다 (가운데 칸에 '누르면 선택' 테두리)
- **빈 곳을 누르면 취소** — 고르기 전 값으로
- 휴식 `분 : 초` — **초 칸에 치기 시작하면 분 칸을 비운다** → 60 을 치는 동안 `1:60` 이 안 보이고 `= 1:00` 으로 미리 보인다. 자판 완료 = 엔터
- 종목 추가는 **카드 맨 아래 검색칸 하나** — 누르면 자판 위로 올라온다
- **이름으로 부위 · 장비 자동 추천** — 이름에 `벤치` → 가슴, `컬` → 팔 … / 이름에 장비가 없으면 후보 칩(예: `벤치` → 바벨 · 머신 · 스미스). 규칙표는 시안 코드의 `부위규칙` · `장비후보`
- 루틴 이름이 두 번 나오던 것 정리, 종목 추가 화면 정돈

## 3. 운동 중

- **시작 안 한 종목은 접는다** (홍겸 님 원래 규칙). 지금 종목만 펼침. 슈퍼세트 상자도 누르면 부드럽게 펼치고 접힌다
- 휴식 칸 색: 초록 → 절반 이하 파랑 → 5초 이하 빨강 굵게
- **위쪽 그림 칸 (배너)** — 보기 넷 중 설정에서 고름

| 보기 | 칸 | 오른쪽 접힌 더미 |
|---|---|---|
| 근육 2장 | [루틴 전체 근육, 지금 부위 확대] | 없음 (사진 안 씀) |
| 근육 + 사진 | [전신 ↔ 확대가 세트마다 번갈아, 사진 1장] | 사진 9장 |
| 사진 1장 | [사진] | 9장 |
| 사진 2장 | [사진, 사진] — 폭 절반씩 | 8장 |

  - 세트가 끝날 때마다 사진이 **무작위로 바뀐다**. 나가는 칸은 오른쪽 끝으로 **얇게 접혀** 들어가고, 새 칸은 그 더미에서 펼쳐져 나온다 (애니메이션)
  - 휴식 동안은 칸이 커진다 (시안 180)
  - 사진만 보는 중에도 **부위가 바뀐 첫 세트에는 새 부위 확대가 한 번** 나온다 — *제 제안*
  - 근육 1번 칸 = 루틴 전체: 끝낸 부위가 빨갛게 쌓인다 / 2번 칸 = 지금 부위: 세트마다 차오른다
  - ✕ 로 배너를 감춘다
  - ⚠ 시안의 근육 그림은 **react-body-highlighter (MIT, © 2020 GV79)** 좌표를 옮긴 것. 앱에 넣을 때는 우리 그림(07 근육지도)으로 바꾸거나, 그대로 쓰면 MIT 저작권 표시를 넣는다

## 4. 종목 사진

- 종목당 최대 10장. 종목 줄을 펼치면 맨 위에 **72×72 사진 칸 가로 한 줄**, 첫 칸이 `사진 추가`, 넘치면 옆으로 밀기
- 목록 줄 왼쪽에 28 크기 작은 사진

## 5. 운동 레포트 · 캘린더

- 레포트: 제목 22, 요약 세 칸(세트 · 볼륨 · 시간)은 같은 크기 카드 + 직전 대비 ▲▼, 종목 목록만 상자 안에서 넘김. 버튼 `기록 저장하고 끝내기 · 운동으로 돌아가기 · 기록 없이 끝내기`
- 캘린더: 펼친 주는 **종목 수만큼만** 커지고, 남는 높이는 다른 주들이 나눈다. 아래 판은 제목 18 · 요약 11 · 버튼 32 한 줄
- ❓ 레포트 아이콘(스타크래프트 부관 느낌) — 요청은 있었으나 시안에 들어갔는지 확인되지 않음. 실제 캐릭터를 그대로 쓰는 것은 저작권 때문에 안 되고, 비슷한 분위기의 우리 아이콘은 가능
