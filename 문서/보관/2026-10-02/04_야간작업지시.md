## 1. 우선순위

### A군 — 먼저 (손이 덜 가고 홍겸 님이 바로 체감)

- **①** 횟수·휴식도 무게처럼 **직접 입력** 가능하게 (지금은 무게만 `<input>`)
- **⑩** 종목 탭의 `›` 를 `∨` 로. 그리고 3개월 대비 **1RM / 단일세트 최고 무게×횟수 /
  한 세션 최대 볼륨**이 얼마나 늘었는지 **숫자와 %로 함께** 표시
- **⑭** 종목 탭 맨 아래 **`＋ 종목 추가` 버튼이 작동하지 않는다. 고칠 것** (핸들러가 없다)
- **⑫** 루틴 안에서 종목을 편집할 때 팝업 띄우지 말고, 운동 화면처럼
  **세트수 - 무게 - 횟수 - 휴식시간** 을 한 줄에서 바로 고치게
- **⑯** 루틴 이름/순서를 팝업 없이 — 루틴 줄 옆에 **톱니바퀴 또는 위아래 화살표**
  → **팝업을 전반적으로 줄이는 방향.** 홍겸 님이 팝업을 싫어한다고 분명히 말했다
- **⑧** 루틴 안 종목에 **휴지통** 아이콘 (지금은 팝업 안에 "이 루틴에서 빼기"로 숨어 있다)
- **⑰** 캘린더의 글자·칸을 **지금보다 50% 작게**. `종목수·세트수·예상시간`을
  **루틴 이름과 같은 줄**로. "달력의 루틴을 꾹 눌러 옮길 수 있습니다" 안내문은 **지우고**
  나중에 ⓘ 설명서에 넣기로 → `01_업데이트예정.md` 에 옮길 것

- **⑪⑬⑭** **카테고리(부위) 추가·삭제.** 종목 탭에서 만든 카테고리가
  **루틴 → 종목 고르기 탭에도 그대로 나와야 한다** (같은 목록을 본다).

- **⑥** 기록 저장/기록없이 끝내기는 그대로 두되, **이미 저장된 기록을 지우는 길**을 추가

  3. `아니오` → 아무 일도 없음

> "루틴 내 종목이 추가되어 단순히 수치가 오른 볼륨이 존재할 수 있기 때문에,

> 나한테 여러가지 방안을 제안해줬으면 좋겠음. **일단 만들어두고, 추후 업데이트사항에 반영.**"

→ **일단 하나를 골라 만들고, 대안 몇 가지를 `01_업데이트예정.md` 에 적어 둘 것.**

- 세트당 평균 볼륨으로 견주기 (세트 수 변화에 영향을 안 받음)

- 종목 구성이 바뀐 날은 **루틴 성장율 선에서 빼고** 점선으로 표시
- 루틴에 원래 있던 종목만으로 계산 (추가/불러온 종목 제외 — 지금 방식)

## 3. ⑦ 슈퍼세트 — 자세히

### 조작 방법 (홍겸 님이 구체적으로 지정했다)

```
종목을 누름        → 테두리가 강조된다
                  → 박스가 진해지면서 약 0.2초 뒤에 팝업(설정)이 뜬다
1초 이상 길게 누름 → 드래그 시작
드래그해서 다른 종목과 겹침 → 두 종목이 슈퍼세트로 묶인다
슈퍼세트를 다시 길게 눌러 세 번째 종목에 겹침 → 세 번째도 슈퍼세트에 편입
```

### 규칙

- 슈퍼세트 = 한 세션 안에서 **동시에 진행**하는 종목 묶음 (예: 덤벨컬 – 해머컬)
- **볼륨을 따로 관리한다.** 슈퍼세트 안에서 한 덤벨컬은
  **단일 종목 덤벨컬과 다른 성장율 데이터**를 가진다
  → 기록에 "이 종목이 어느 슈퍼세트에서 수행됐는지"를 남겨야 한다
- **`＋` 버튼의 뜻이 바뀐다.** 단일 종목에서는 그 종목의 세트가 1개 늘지만,
  슈퍼세트에서는 **묶인 종목 전부에 한 세트씩** 늘어난다
  (덤벨컬–해머컬이면 `＋` 한 번에 둘 다 한 세트씩)

### 참고

`01_업데이트예정.md` ⑧번 `← 이전` 버튼이 "슈퍼세트 관련으로 연결짓기"로 올라가 있다.
슈퍼세트를 만들면서 그 버튼의 쓰임도 같이 정리할 것.

## 5. 작업 결과 (밤 작업이 채울 자리)

### 한 것 — 2026-09-21 새벽 (A군 완료)

모두 headless 크로미움 440×900 으로 실제로 눌러 확인했다. 콘솔 오류 없음.

| 항목 | 한 일 | 확인한 것 |
|---|---|---|
| **①** | 운동 화면 설정칸의 **횟수·휴식도 직접 입력**. 휴식은 `2:15` 도 `90` 도 받는다 | 13회·2:15 입력 → 반영, `90` → `01:30` 으로 |
| **⑩** | 종목 탭 `›` → **`∨`**. 줄을 펼치면 **최대 1RM / 단일세트 최고 / 한 세션 볼륨**을 `지금 · 이전 · +%·차이` 표로 | 벤치프레스 `80.0 / 73.3 / +9% +7kg` 등 |
| **⑩⑫** | 종목 이름·캘린더 표시 이름·부위를 **그 줄에서** 고친다. **팝업(종목 편집 시트) 삭제** | 표시이름 저장 확인 |
| **⑭** | **`＋ 종목 추가` 가 이제 작동한다** (예전엔 핸들러가 없었다). 이름·부위·장비를 받는다 | 케이블 크런치 추가 확인 |
| **⑪** | 카테고리를 **종목과 따로** 들고 있게 바꿨다. ⚙ 로 추가·삭제 (종목이 있으면 함께 삭제 여부를 묻는다) | `전완` 추가 → 칩에 바로 |
| **⑬⑭** | **루틴 → 종목 고르기에도 카테고리 칩.** 종목 탭에서 만든 카테고리가 그대로 나온다. ⚙ 로 `전체 숨기기` / `즐겨찾기 숨기기` | 복근 칩 → 케이블 크런치까지 나옴 |
| **⑧** | 루틴 안 종목마다 **🗑 (이 루틴에서 빼기)** | 3개 → 2개 |

### 판단해서 고른 것 (홍겸 님 확인 필요)

1. **영양 목표 기본값** — 단백질 120g / 크레아틴 5g 으로 두었다.
   **의학적 권고가 아니라 자리를 잡아둔 숫자**이고, 화면에도 그렇게 적었다.
   크레아틴 하루 5g 은 유지 용량으로 널리 쓰이는 값이지만, 본인에게 맞는 양은
   전문가와 정해서 설정에 넣어 쓰시는 게 맞다.
2. **신체 기록을 영양 탭 안에 넣었다.** 탭을 더 늘리고 싶지 않아서다.
   따로 떼는 게 나으면 말씀해 주시면 옮긴다.
3. **체지방을 근육량으로 계산하지 않았다.** 인바디의 골격근량만으로는
   체지방을 구할 수 없다. 그래서 체지방량 또는 체지방률 중 하나는 직접 넣어야 한다.
   이 사실을 화면에도 적어두었다. (억지로 계산해서 틀린 값을 보여주지 않으려는 것)
4. **루틴 달성도는 세트 기준**이다 (전에 확정). 볼륨은 따로 `한 것/목표` 로 보여준다.
5. **캘린더 안내문 제거** — "달력의 루틴을 꾹 눌러 옮길 수 있습니다" 는 지웠다.
   ⓘ 설명서를 만들 때 넣기로 하고 `01_업데이트예정.md` 로 옮겼다.
