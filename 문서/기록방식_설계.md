## 정하는 곳 (저장 늘리지 않음)
- `종목.방식: String? = null` — null 이면 **이름으로 자동**(사전 표 · 이름에 '어시스트' · 장비 맨몸 · 맨몸 복근). 커스텀 종목만 값을 가진다
- 자동 표는 한곳(`data/` 의 기록방식 표)에 모은다

## 저장은 어떻게 (추천 = 기록에 '실제 무게')
- 루틴 · 기본 세팅 · 운동 중 칸 = **입력값**(추가 · 보조) 그대로
- **기록(날기록)에 남길 때만** 실제 무게로 바꿔 넣는다 → 볼륨 · 1RM · 피로 · 보고서 · 업적이 고칠 것 없이 맞게 나온다.
  체중이 나중에 바뀌어도 그날 기록은 그날 체중 그대로 (09-27 결정)
- 운동 중 화면의 볼륨 · 보고서처럼 세션 값으로 바로 세는 곳은 같은 함수로 바꿔 센다
- 플랜 줄(턱걸이 어시스트 등)은 플랜이 따로 셈 → 건드리지 않는다
- 지난 기록을 세션으로 불러오는 곳이 있으면 거꾸로(실제 → 입력) 바꾼다 — 찾아볼 것
- 옛 기록(맨몸 무게 0 으로 적힌 것)은 그대로 둔다(지금처럼 체중×0.6 으로 셈)

## 화면
- 기본 세팅 표 · 운동 중 · 루틴 세트 칸: 방식에 따라 머리 글('추가 kg' · '보조 kg' · '시간') · 칸(시간은 m:ss, ±5초) · 칸 아래 작게 '= 69kg'
- 커스텀 종목만: 새 종목 시트에서 방식 고르기(머리 '⇄' 또는 칩 — 다음 대화에서 정함)
- 시간 종목 운동 중: ▶ 시작 → 줄어드는 타이머 → 끝나면 진동 + 자동 체크 (나중 단계)
- 유산소: 시작 → 시간 흐름 → 마침 → 거리 입력 (마지막 단계 · 저장 칸이 새로 필요)

## 단계 (한 대화 = 한 단계)
1. 방식 표 + 기록에 실제 무게 넣기 + 계산 (data · 감시관) — 화면은 머리 글 · '= 69kg' 만
2. 시간 칸(m:ss) · 숨길 칸 · 커스텀 방식 고르기 (화면)
