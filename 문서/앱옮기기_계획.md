## 3단계 — 합치기 · 검수
1. `port/all` 에 foundation → W → R → C → RT → EX → PF → PS 순서로 합치고 충돌을 푼다 → CI 초록
2. 검수 도우미 4명(서로 다른 역할, `watchdog` 정의 사용):
   - **시안 대조** — 화면마다 시안 함수와 하나하나 비교(글자 · 순서 · 동작), 빠진 것 목록
   - **뒤죽박죽 사용** — 운동 중 종목 빼기/끌기/넣기를 섞어 하기 · 쉬는 중 끝내기 · 같은 날 기록 여러 개 지우고 되돌리기 · 같은 이름 종목 · 플랜 종목 지우기 · 앱 껐다 켜기 · 시트 열린 채 탭 바꾸기 등을 코드로 따라가 버그 찾기 + 순수 함수 시험 추가
   - **저장 안전** — 옛 JSON(스키마 14 이하 · 실제 v0.13.0 저장 꼴)이 그대로 열리는지, 빈 값 · 이상한 값, 저장 왕복 시험
   - **화면 규칙** — 11_UI지침 값(글자 · 여백 · 높이 · 색 토큰만 · Color 직접 금지) · 문자열 템플릿 `${n}회` · `글()` 줄 수 · 접근성 글
3. ❌·⚠ 고침 → 같은 검수 다시 → 모두 통과하면 main 에 합치기 → `build.yml` 빌드 → APK 링크 보고
4. versionName 0.14.0 (build.gradle.kts 21~22줄), `00_작업현황.md` 새 절
